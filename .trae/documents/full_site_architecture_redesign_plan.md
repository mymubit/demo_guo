### 1.2 各类页面原有结构缺陷

#### 【问题共性】全站级底层问题
1. **导航框架割裂**：C端顶栏导航与Admin侧边栏导航两套完全独立的交互范式，面包屑逻辑不统一
2. **容器标准混乱**：页面边距从 `p-4` 到 `p-9` 随意使用，内容区最大宽度无统一规范
3. **信息层级倒置**：次要说明文字与核心操作按钮视觉权重相同，核心信息被淹没
4. **状态展示缺失**：加载、空数据、报错、无权限、网络异常等状态无统一处理，各页面自行实现
5. **响应式为简单缩放**：移动端未做结构重排，只是把PC布局缩小堆叠，操作区拥挤
6. **组件结构不一致**：表格、卡片、表单在不同页面结构不同，相同功能操作按钮位置不同

---

#### 营销首页（Home）缺陷
- **信息动线断裂**：Hero区 → 功能介绍 → 用户证言 → FAQ → CTA，滚动路径无引导，用户容易中途流失
- **首屏价值不聚焦**：Hero区同时放海报、标语、CTA按钮、统计数字，视觉焦点分散
- **功能模块平铺**：6个功能卡片无分组无重点，用户无法快速理解核心差异
- **CTA按钮重复冗余**：页面中出现超过5个"立即开始"按钮，无场景区分
- **移动端堆叠混乱**：网格直接变成1列，卡片间距过大，首屏看不到核心价值

---

#### 创作工作台（WorkspacePage）缺陷
- **分栏比例僵化**：左侧角色列表固定宽度，右侧内容区无法利用大屏空间，小屏拥挤
- **角色状态展示低效**：每个角色的进度、状态、输出内容全部折叠在卡片中，需要逐个点击查看
- **核心内容区无层级**：角色输出内容直接铺在页面，没有区分「当前激活内容」和「历史执行记录」
- **操作区位置不合理**：执行按钮、暂停按钮、导出按钮散落在页面各处，操作动线长
- **进度展示不直观**：整体完成度只靠一个百分比数字，无法直观看到哪些阶段完成哪些未完成
- **移动端不可用**：左右分栏在窄屏完全挤压，无法正常操作

---

#### 项目列表页（Drama/index、Works/index）缺陷
- **筛选区结构混乱**：搜索框、状态筛选、排序、新建按钮排布无逻辑，主次不分
- **卡片信息密度失衡**：项目卡片要么信息太少（只有标题）要么信息过载（把所有元数据都堆上）
- **空状态设计缺失**：没有项目时只有一个简单按钮，无引导、无示例、无模板推荐
- **批量操作入口缺失**：无法批量删除、批量导出，只能单项目操作
- **分页逻辑隐晦**：要么无限滚动无反馈，要么传统分页跳转不直观
- **新建项目弹窗层级问题**：弹窗字段太多，一上来就让用户填所有参数，门槛太高

---

#### 内容详情页（ScriptsPage、Works/Detail）缺陷
- **阅读体验差**：剧本内容直接靠CSS渲染，没有字体大小调节、行间距调节、夜间/日间模式切换
- **目录导航缺失**：长剧本没有侧边目录，无法快速跳转到某一集某一场
- **操作区与内容区混杂**：导出、分享、质量评分等操作按钮插在正文中间，打断阅读流
- **质量报告展示碎片化**：各维度评分、问题列表、改进建议散落在不同区域，无法形成整体认知
- **相关内容无关联**：看完某一集没有推荐下一集、没有回到大纲入口

---

#### 数据列表页（Orders、Wallet、Admin列表）缺陷
- **表头固定问题**：滚动时表头不固定，看下面数据不知道对应哪一列
- **筛选区占空间太大**：高级筛选全部展开，把表格挤到首屏以下
- **操作列位置混乱**：有的表格操作列在最左，有的在最右，有的每行都有3个以上按钮
- **无数据汇总区**：表格上方没有汇总数据（总金额、总数量、选中项），用户需要自己算
- **表格行 hover 反馈弱**：选中行、hover行视觉区分不明显
- **移动端表格不可用**：直接横向滚动，列名和数据对不上

---

#### 表单配置页（Admin配置、Profile、登录注册）缺陷
- **字段分组逻辑弱**：所有字段一顺排列，没有分组、没有小标题，长表单让人望而生畏
- **错误提示位置不一致**：有的在输入框上方，有的在下方，有的是toast，有的是行内提示
- **提交按钮布局混乱**：取消/提交按钮有的左对齐有的右对齐有的居中，主次按钮视觉权重反了
- **分步表单无进度指示**：多步骤表单没有进度条，用户不知道自己在哪一步、还剩几步
- **配置项无即时反馈**：修改配置后不知道是否生效，需要手动刷新查看

---

#### 仪表盘（Admin Dashboard）缺陷
- **指标卡片平铺**：所有指标卡片大小一样，没有区分核心KPI和次要指标
- **图表无交互**：静态图表无法hover查看详情、无法切换时间范围、无法下钻
- **异常信息无优先级**：告警、通知、日志混在一起，高危异常和普通提示无视觉区分
- **时间范围选择器隐蔽**：全局时间筛选藏在角落，用户容易忽略
- **快捷入口缺失**：高频操作没有快速入口，需要多级菜单跳转

---

#### 弹窗/浮层缺陷
- **层级管理混乱**：z-index随意设置，会出现弹窗盖弹窗、弹窗被遮挡问题
- **关闭逻辑不一致**：有的点蒙层能关，有的不能，有的有关闭按钮有的没有
- **弹窗大小无规范**：小确认弹窗和大表单弹窗一样宽度，小内容留大片空白
- **二次确认浮层滥用**：所有删除操作都用浏览器原生confirm，风格不统一
- **弹窗内表单无滚动处理**：内容多的时候弹窗超出视口，底部按钮被遮挡

## 二、全新底层布局骨架方案

### 2.1 全局布局框架重构

#### 全站统一骨架标准
```
┌─────────────────────────────────────────────────────────────┐
│  全局导航层（Global Navigation）                              │
│  [高度：64px] 固定定位，滚动后加毛玻璃背景                    │
├──────────┬──────────────────────────────────────────────────┤
│          │  面包屑 + 页面标题区（Page Header）                │
│          │  [高度：自适应 80-120px]                           │
│          ├──────────────────────────────────────────────────┤
│  侧边栏  │  页面主内容区（Page Content）                      │
│  （可选） │  [最小高度：calc(100vh - 64px - 80px)]             │
│  宽度：   │  ┌──────────────────────────────────────────┐    │
│  240-280px│  │  内容网格区（Content Grid）              │    │
│  可折叠   │  │  按页面类型使用不同网格模板               │    │
│          │  └──────────────────────────────────────────┘    │
│          ├──────────────────────────────────────────────────┤
│          │  页脚（仅C端营销页需要，B端工作台无页脚）          │
└──────────┴──────────────────────────────────────────────────┘
```

#### 导航框架重构
| 端 | 导航模式 | 结构说明 |
|---|---------|---------|
| **C端用户端** | 顶部导航栏 | 左侧Logo → 中部导航菜单 → 右侧用户/钱包/CTA<br>滚动时导航栏背景从透明变毛玻璃，缩小高度 |
| **B端Admin端** | 侧边栏 + 顶部栏 | 侧边栏可折叠（240px → 64px），顶部栏放面包屑+全局操作<br>移动端侧边栏变抽屉，从左侧滑出 |
| **Drama创作端** | 三级导航 | 顶部全局导航 → 工作台左侧角色导航 → 内容区局部Tab<br>采用"全局-局部-上下文"三级导航体系 |

### 2.2 各类页面布局骨架方案

#### 【类型1】营销首页（Landing Page）
**信息层级结构图**：
```
首屏核心区（100vh）
├─ 顶部导航（透明）
├─ 主标语（左60%）
│  ├─ 小标签（产品定位）
│  ├─ H1 主标题（2行）
│  ├─ 辅助说明（1行）
│  └─ 双CTA按钮组（主按钮+次按钮）
└─ 核心价值可视化（右40%）
   └─ 创作流程动效预览图

信任背书区
├─ 4个核心数据指标（横向排列）
└─ 合作平台/用户Logo墙

核心功能区
├─ 区块标题
├─ 3个主功能卡片（大卡片，横向，左图右文/左文右图交替）
└─ 每个卡片带"了解更多"深入链接

创作流程区
├─ 区块标题
├─ 7步流程可视化（横向时间轴，已完成/当前/未完成状态）
└─ 流程说明展开区

用户证言区
├─ 区块标题
└─ 4条证言卡片（2x2网格，带头像、身份、评价内容）

价格/CTA区
├─ 套餐对比（3列卡片）
└─ 最终转化CTA

FAQ区
├─ 折叠式FAQ列表（手风琴模式）
└─ 问题反馈入口

页脚
```

**区块尺寸规范**：
- 首屏最小高度：100vh，不超过120vh
- 区块间距：120px（PC）/ 64px（移动端）
- 内容最大宽度：1280px，居中
- 左右边距：48px（PC ≥ 1024px）/ 24px（移动端）

#### 【类型3】创作工作台（三栏自适应布局）
**布局骨架（PC端）**：
```
┌───────────┬──────────────────────────────┬────────────────┐
│           │  阶段进度条（高度48px）        │                │
│           │  [选题]→[世界观]→[人设]→[大纲]→[剧本]→[审查]│                │
```

**布局骨架（移动端）**：
```
┌─────────────────────────┐
│  阶段进度条（横向滚动）   │
├─────────────────────────┤
│  角色Tab（横向滚动）      │  ← 代替左栏，点击切换角色
├─────────────────────────┤
│                         │
│  当前角色输出内容区       │
│  （单栏全屏展示）         │
│                         │
├─────────────────────────┤
│  [操作按钮]  [查看详情]   │  ← 底部操作栏固定
└─────────────────────────┘
```

**核心逻辑重构**：
1. **三栏可独立折叠**：左栏角色列表、右栏详情面板都可以收起，让中间内容区占满宽度
2. **阶段进度置顶**：创作8个阶段做成顶部进度条，点击可快速跳转到对应阶段，清晰展示当前位置
3. **角色按阶段分组**：左栏角色不再平铺，按照8个创作阶段分组，完成的阶段收起，当前阶段展开
4. **输出内容卡片流**：中间区不是所有内容平铺，而是按执行顺序排列卡片，每个卡片默认收起预览，点击展开完整内容
5. **上下文操作固定**：常用操作（执行下一步、暂停、导出）固定在可视区域，不需要滚动找

**阅读体验重构**：
1. **正文区宽度限制**：最佳阅读宽度720px，居中展示，不随屏幕拉伸，减少眼球转动距离
2. **目录导航常驻**：左侧目录默认展开，点击场记号直接跳转，滚动时目录自动高亮当前位置
3. **工具栏固定顶部**：字号调节（大/中/小）、行高调节、日/夜/护眼三种模式、导出按钮常驻
4. **质量报告可切换**：右侧质量报告默认展开，也可以一键收起让正文全屏；正文内问题处有标记，点击标记跳转到对应问题详情
5. **翻页/分集导航**：底部固定上一集/下一集按钮，键盘左右键也可翻页

#### 【类型5】数据列表页（工具栏 + 表格标准结构）

### 3.3 组件结构标准

#### 按钮位置与优先级规则
1. **页面级主操作按钮**：始终放在页面标题区右上角，左对齐还是右对齐看布局
2. **表单操作按钮**：固定表单底部，**右对齐**，主按钮在最右，次按钮在主按钮左边
3. **弹窗操作按钮**：弹窗底部，**右对齐**，确认按钮在右，取消在左
4. **卡片内操作**：卡片右下角，或hover时浮层出现
5. **表格行操作**：hover行时显示在单元格右侧，默认隐藏
6. **按钮视觉权重**：主按钮 > 次按钮 > 文字按钮 > 危险按钮（单独放左侧或特殊样式）

#### 卡片结构标准
```
┌─────────────────────────────────┐
│  卡片头部（可选）                │
│  [标题]                [操作区]  │
├─────────────────────────────────┤
│                                 │
│  卡片内容区                      │
│                                 │
├─────────────────────────────────┤
│  卡片底部（可选）                │
│  [元信息]              [操作按钮] │
└─────────────────────────────────┘
```
- 卡片内边距：24px
- 卡片圆角：12px
- 卡片之间间距：24px
- 卡片头部/底部有分割线（1px 浅色边框）

#### 状态反馈标准
| 状态 | 触发时机 | 展示形式 |
|-----|---------|---------|
| 页面加载 | 首次进入页面、路由切换 | 骨架屏（和页面结构一致）|
| 局部加载 | 表格刷新、加载更多 | 目标区域加载骨架/旋转图标，不要全局loading |
| 按钮加载 | 点击提交/保存 | 按钮内旋转图标+文字变"提交中..."，按钮禁用 |
| 操作成功 | 保存、创建、删除成功 | Toast提示（右上角，3秒自动消失），如果是创建成功可带"查看详情"按钮 |
| 操作失败 | 接口报错、校验失败 | 行内错误提示（表单）+ Toast（全局错误），不要弹窗 |
| 空数据 | 列表/表格无数据 | 区域内空状态组件（插图+文字+操作按钮），不要整页空白 |
| 网络错误 | 断网、接口超时 | 整页错误组件（带重试按钮） |
| 无权限 | 访问未授权页面 | 403页面，带返回首页按钮 |

### 3.4 多端适配底层逻辑

#### PC端（≥1024px）布局原则
- 充分利用大屏空间，采用多栏布局
- 高频侧边导航可折叠，提供更大内容区
- 鼠标悬停（hover）展示更多操作
- 键盘快捷键支持（左右翻页、Ctrl+S保存等）

#### 平板端（768px - 1024px）布局原则
- 三栏布局变两栏，默认收起最右侧详情栏
- 卡片网格从3列变2列
- 隐藏hover操作，改为点击显示
- 触摸目标尺寸≥44px × 44px

#### 移动端（<768px）布局原则（不是缩放，是结构重排）
1. **导航**：顶部导航简化为Logo+菜单按钮+核心操作（1-2个），侧边栏变全宽抽屉
2. **列表页**：筛选栏折叠，只保留搜索框和一个筛选按钮，点击展开筛选面板
3. **表格**：自动转为卡片列表视图，不使用横向滚动
4. **工作台**：三栏变单栏，Tab切换代替左右分栏，底部固定操作栏
5. **阅读器**：目录默认收起，点击按钮滑出抽屉，正文全屏显示
6. **表单**：所有字段单列排列，不使用两列布局
7. **弹窗**：小弹窗居中显示，大弹窗/表单变全屏页面（不是弹窗）
8. **触摸优先**：所有可点击元素尺寸≥44px，间距≥8px，避免误触

## 五、风险控制与兼容说明

1. **不删减业务功能**：所有重构只改变展示结构和排布，不删除原有功能，所有业务接口保持不变
2. **灰度重构**：优先重构Drama创作相关核心页面，验证效果后再推广到其他页面
3. **组件复用**：新布局组件尽量复用现有逻辑，只改结构和样式，不重写业务逻辑
4. **视觉样式保持兼容**：现有深色主题+金色主色调保持不变，只改布局骨架和信息结构，不换配色方案
5. **逐步验证**：每重构完一个页面类型，在浏览器验证PC/平板/移动端三种尺寸下的展示和操作
