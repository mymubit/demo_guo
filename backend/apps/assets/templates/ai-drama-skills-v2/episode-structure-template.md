## 一、四段式结构总览

```
AI短剧单集标准结构（60-180秒）

┌─────────────────────────────────────────────────────────┐
│ 阶段一：强开场钩子（0-3秒）     │ 占比 3%                  │
│ 阶段二：情境建立（3-15秒）     │ 占比 13%                 │
│ 阶段三：情绪升级/矛盾激化（15-60秒）│ 占比 50%              │
│ 阶段四：结尾悬念钩子（50-60秒）│ 占比 8%                │
│ 过渡/缓冲（各阶段间）           │ 占比 26%                 │
└─────────────────────────────────────────────────────────┘
```

## 二、各阶段详细规范

### 阶段一：强开场钩子（0-3秒）

**核心目标**: 3秒内抓住观众注意力，防止划走

| 项目 | 规范 |
|------|------|
| **时长** | 严格控制在0-3秒（最长不超过5秒） |
| **必须元素** | 冲突画面 / 悬念提问 / 视觉冲击 / 金句开场 |
| **禁止元素** | 环境交代 / 人物介绍 / 背景铺垫 / 片头Logo |
| **台词限制** | 不超过10个字，或无台词纯画面 |
| **AI画面要求** | 特写/近景为主，人物占画面60%+，高对比度 |
| **音效要求** | 强冲击音效（碎裂/爆炸/心跳/尖叫等） |

**钩子类型分类**：

| 类型 | 说明 | 示例 | AI画面建议 |
|------|------|------|-----------|
| **视觉冲击型** | 强烈画面瞬间抓住视线 | 女主被扇耳光特写 | 特写面部+慢动作+高对比 |
| **悬念型** | 抛出悬念问题 | "你确定要这么做？" | 近景对峙+眼神特写 |
| **冲突爆发型** | 直接进入冲突高潮 | "我才是真正的继承人！" | 中景+手势+表情爆发 |
| **金句型** | 震撼性台词开场 | "三年了，该还了。" | 特写嘴唇+眼神+暗色调 |
| **反转型** | 出乎意料的画面 | 女主从棺材中坐起 | 全景→特写快速切换 |
| **危机型** | 紧急危险情境 | 刀架在脖子上 | 特写刀刃+紧张表情 |

**校验标准**: 去掉前3秒，观众是否还有理由继续看？如果没有，钩子不合格。

### 阶段二：情境建立（3-15秒）

**核心目标**: 快速建立当前场景的核心冲突，让观众理解"发生了什么"

| 项目 | 规范 |
|------|------|
| **时长** | 3-15秒（约12秒） |
| **功能** | 交代角色状态 + 核心矛盾 + 情绪基调 |
| **节奏** | 快节奏，每句台词不超过10字 |
| **场景数** | 1个场景（不换景） |
| **AI画面要求** | 中景/近景交替，避免全景，保持视觉紧凑 |
| **信息密度** | 每秒传递1-2个关键信息 |

**情境建立模板**（写分集大纲，不进 03 正文）：

| 要素 | 说明 |
|------|------|
| 场景延续 | 与开场同场或紧接转场 |
| 角色状态 | 主角当前处境（1 句话） |
| 核心矛盾 | 本集要面对的问题（1 句话） |
| 情绪基调 | 紧张 / 愤怒 / 悲伤 / 震惊 |
| 衔接 | 自然进入情绪升级段 |

**校验标准**: 15秒内观众是否理解"发生了什么"？如果不知道核心冲突，情境建立不合格。

### 阶段三：情绪升级/矛盾激化（15-60秒）

**核心目标**: 推进主线，情绪层层递进，矛盾不断激化

| 项目 | 规范 |
|------|------|
| **时长** | 15-60秒（约45秒，占单集50%） |
| **功能** | 冲突升级 / 信息揭露 / 关系变化 / 情感推进 |
| **节奏** | 每15秒一个情绪转折点 |
| **场景数** | 1-2个场景（最多1次换景） |
| **台词密度** | 每句台词8-15字，对话节奏紧凑 |
| **AI画面要求** | 对话场景近景为主，情绪特写穿插 |

**三段式情绪升级结构**：

```
【矛盾初步升级】（15-30秒）
├── 内容：新信息/新冲突/新角色介入
├── 情绪强度：★★★☆☆（中等偏上）
├── 转折点：一个让局势变化的关键信息
└── 台词示例："你以为你赢了？"

【情绪进一步激化】（30-45秒）
├── 内容：对峙/争吵/内心挣扎/关系破裂
├── 情绪强度：★★★★☆（高强度）
├── 转折点：矛盾升级到不可调和
└── 台词示例："从今天起，我们恩断义绝！"

【段落高潮】（45-60秒）
├── 内容：打脸/反转/情感爆发/关键抉择
├── 情绪强度：★★★★★（最高点）
├── 转折点：本集最强烈的冲突爆发
└── 台词示例："这一切，都是你自找的！"
```

**校验标准**: 情绪曲线是否持续上升？如果出现平缓段或下降段，情绪升级不合格。

### 阶段四：结尾悬念钩子（50-60秒）

**核心目标**: 让观众想知道"接下来会怎样"，驱动追更

| 项目 | 规范 |
|------|------|
| **时长** | 50-60秒（最后10秒） |
| **必须元素** | 反转 / 秘密揭露 / 危机降临 / 关系突变 / 身份揭秘 |
| **禁止元素** | 完整收束 / 平淡过渡 / 总结性台词 / "未完待续"字幕 |
| **台词限制** | 不超过15个字，或无台词纯画面+字幕 |
| **AI画面要求** | 特写表情 / 黑屏字幕 / 悬念音效 / 定格画面 |
| **音效要求** | 悬念音效（心跳加速/低频嗡鸣/突然静音） |

**结尾钩子类型分类**：

| 类型 | 说明 | 示例 | AI画面建议 |
|------|------|------|-----------|
| **反转型** | 真相揭露/敌友反转 | 真正的幕后黑手露面 | 特写面部+反转音效 |
| **危机型** | 新的威胁出现/处境恶化 | 刀从背后刺来 | 黑屏+音效+字幕 |
| **悬念型** | 关键问题未解答 | "她到底是谁？" | 特写疑惑表情+定格 |
| **关系型** | 人物关系突变/新人物登场 | 前男友突然出现 | 中景+震惊表情 |
| **秘密型** | 暗示性台词/意味深长 | "你母亲，还活着。" | 特写嘴唇+低沉音效 |

**校验标准**: 看完后观众是否想知道"接下来会怎样"？如果不想，结尾钩子不合格。

## 四、平台差异化适配

| 平台 | 推荐时长 | 开场钩子偏好 | 结尾钩子偏好 | 情绪升级节奏 |
|------|---------|-------------|-------------|-------------|
| **抖音** | 60-90秒 | 视觉冲击型优先 | 反转型/危机型 | 快节奏，每10秒转折 |
| **快手** | 90-120秒 | 悬念型/金句型 | 关系型/秘密型 | 中等节奏，注重情感 |
| **微信** | 120-180秒 | 金句型/悬念型 | 悬念型/秘密型 | 慢节奏，注重铺垫 |
| **B站** | 120-180秒 | 反转型/金句型 | 反转型/悬念型 | 中等节奏，注重逻辑 |

### 5.1 分集大纲设计备忘（写 `02_项目设定/分集大纲`）

| 段落 | 时长 | 设计要点 |

```

【闪回开始】

【闪回结束】

△林婉儿握紧拳头。
律师：还有一件事。
```

## 六、结构校验清单

| 校验项 | 校验标准 | 不合格处理 |
|--------|---------|-----------|
| **开场钩子存在** | 前3秒必须有钩子标注 | P0级问题，必须补充 |
| **开场钩子类型** | 必须属于6种钩子类型之一 | P1级问题，建议修改 |
| **开场钩子画面** | 必须有AI画面描述 | P1级问题，建议补充 |
| **情境建立完整** | 15秒内交代核心冲突 | P0级问题，必须补充 |
| **情绪升级递进** | 情绪曲线持续上升，无平缓段 | P1级问题，建议优化 |
| **每15秒转折** | 情绪升级段每15秒有转折点 | P2级问题，建议增加 |
| **结尾钩子存在** | 50-60秒必须有悬念钩子 | P0级问题，必须补充 |
| **结尾钩子类型** | 必须属于5种结尾钩子类型之一 | P1级问题，建议修改 |
| **结尾不收束** | 结尾不能完整解决问题 | P0级问题，必须修改 |
| **单集时长合规** | 在目标平台时长范围内 | P1级问题，建议调整 |
