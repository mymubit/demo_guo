## 1. 镜头语言分类体系总览

### 1.1 景别分类（按画面取景范围）

| 景别 | 定义 | 画面效果 | 适用场景 |
|------|------|---------|---------|
| **大特写** | 极近距离聚焦局部细节（如眼睛、嘴唇、手指） | 极强冲击力，放大情绪细节 | 情绪爆发、关键线索揭示、内心变化 |
| **特写** | 人物面部或单一物体满屏 | 聚焦情绪、强调细节 | 情绪表达、关键道具、表情变化 |
| **近景** | 人物胸部以上 | 清晰表情+少量环境 | 对话场景、情绪交流 |
| **中景** | 人物腰部以上 | 兼顾表情与肢体 | 常规对话、轻度动作 |
| **全景** | 人物全身或场景全貌 | 展示环境、人物关系 | 场景建立、位置交代、动作展示 |
| **远景** | 人物在画面中很小，突出环境 | 氛围营造、史诗感 | 大场面、环境揭示、孤独感 |

### 1.2 运镜方式分类（按摄影机运动）

| 运镜方式 | 英文 | 情绪效果 | 适用场景 |
|---------|------|---------|---------|
| **推镜头** | Push / Dolly In | 紧张感、逼近感、强调 | 审问、对峙、发现秘密、情绪逼近 |
| **拉镜头** | Pull / Dolly Out | 疏离感、揭示环境、孤独感 | 角色孤立、真相揭示、环境展开 |
| **摇镜头** | Pan | 不安感、搜索感、信息扫描 | 搜寻、追逐、混乱场面、环境展示 |
| **移镜头** | Track / Dolly | 流动感、跟随感、探索感 | 行走跟拍、探索环境、长镜头叙事 |
| **跟镜头** | Follow | 紧迫感、追踪感、代入感 | 追逐、逃跑、紧张行动、主观代入 |
| **升/降镜头** | Boom / Crane | 气势感、上帝视角、情绪升华 | 大场面、高潮、结局升华 |
| **晃镜头** | Shake / Handheld | 混乱感、紧张感、真实感 | 打斗、地震、恐慌、主观眩晕 |
| **旋转镜头** | Spin / 360 | 眩晕感、时间变化、情绪转折 | 穿越、晕倒、情绪崩溃、时间流逝 |

### 1.3 转场方式分类

| 转场类型 | 定义 | 适用场景 |
|---------|------|---------|
| **动作匹配转场** | 前后场景有相似动作连接 | 关门→开门、转身→转身、抬手→放下 |
| **视线转场** | 角色看向某处→该处场景 | 角色看窗外→窗外景象 |
| **声音先入转场** | 先听到声音再出现画面 | 先听到争吵声→切换到争吵场景 |
| **相似体转场** | 形状/颜色相似的物体切换 | 酒杯→月亮、眼睛→车灯 |
| **情绪转场** | 情绪延续到下一场景 | 愤怒表情→摔门而去 |
| **闪回转场** | 进入回忆/闪回 | 回忆触发→过去场景 |
| **黑屏转场** | 画面变黑再亮起 | 时间跳跃、场景切换、情绪缓冲 |
| **叠化转场** | 画面重叠过渡 | 时间流逝、情绪延续、回忆叠加 |

### 1.4 镜头视角分类

| 视角类型 | 定义 | 情绪效果 | 适用场景 |
|---------|------|---------|---------|
| **客观视角** | 第三人称旁观 | 客观、中立、全知 | 常规叙事、全景交代 |
| **主观视角** | 角色第一人称视角 | 代入感强、沉浸感 | 紧张体验、角色感受 |
| **过肩镜头** | 越过一个角色肩膀拍摄另一个 | 对话感、对峙感 | 对话、对峙、谈判 |
| **鸟瞰视角** | 从上往下俯视 | 上帝视角、战略感 | 大场面、布局交代、命运感 |
| **低角度** | 从下往上仰拍 | 压迫感、力量感、威严 | 反派登场、强者压迫、权力展示 |
| **高角度** | 从上往下俯拍 | 弱势感、渺小感 | 弱者视角、被压迫、孤独 |

## 2. 情绪-镜头快速匹配表

> **核心原则**：镜头语言是情绪的视觉化表达。选择镜头时，先确定当前情绪的强度等级，再根据情绪类型匹配最合适的镜头组合。

### 2.1 情绪强度-镜头速查表

| 情绪强度 | 推荐景别序列 | 推荐运镜方式 | 推荐景深 | 画面节奏 |
|---------|------------|------------|---------|---------|
| **1级（压抑/绝望）** | 全景→大特写 | 缓慢推镜头或固定镜头 | 浅景深 | 极慢，每3-5秒切一次 |
| **2级（低落/焦虑）** | 中景→近景 | 轻微摇晃或缓慢横移 | 适中 | 慢，每2-3秒切一次 |
| **3级（波动/紧张）** | 中景↔近景交替 | 推镜头或摇镜头 | 适中偏浅 | 正常，每1-2秒切一次 |
| **4级（强烈情绪）** | 近景↔特写快速切 | 快速推镜头+轻微晃动 | 浅景深 | 快，每0.5-1秒切一次 |
| **5级（极致爆发）** | 特写↔大特写↔特写 | 快速推+定格+晃镜头 | 极浅景深 | 极快，急促切换+定格定格 |

## 3. 镜头组合公式速查

### 3.1 基础镜头组合公式

#### 公式A：情绪建立→升级→爆发（标准三段式）

```
【开场】全景/中景（固定/缓慢移）→ 建立环境
【升级】中景→近景（缓慢推）→ 情绪积累
【爆发】近景→特写/大特写（快速推/定格）→ 情绪释放
```

**应用示例**：
```
【全景】客厅里，一家人正在吃晚饭（建立环境）
→【中景→缓慢推至近景】女主看手机，脸色慢慢变了（情绪积累）
→【特写→快速推至大特写】手机屏幕上赫然写着：你被开除了。（情绪爆发）
```

#### 公式B：反转/揭露时刻

```
【铺垫】近景/特写→固定镜头（营造悬念）
【反转】中景/全景（拉镜头/摇镜头）→ 揭示真相
【反应】特写/大特写（推镜头）→ 展现震惊/情绪
```

**应用示例**：
```
【特写】女主打开信件的手在颤抖（铺垫悬念）
【拉镜头→中景】她读完信，难以置信地抬起头——身后站着的人，正是信中提到的那个人（反转揭示）
【推镜头→大特写】女主瞳孔地震：你...你不是死了吗？（反应）
```

#### 公式C：追逐/紧张序列

```
【跟镜头→晃镜头】主观视角奔跑（代入紧张感）
【摇镜头→快速切】环境快速闪过（混乱感）
【特写→快速推】目标显现→障碍出现（紧张加剧）
【晃镜头→定格】关键时刻（悬念定格）
```

**应用示例**：
```
【跟镜头+晃镜头】男主在人群中拼命奔跑
【摇镜头】周围的人群、灯光飞速闪过
【特写→快速推】男主的手机屏幕亮了——陌生号码来电
【晃镜头→定格】男主伸手接电话，画面定格在手指触碰屏幕的瞬间
```

#### 公式D：甜蜜/温馨氛围

```
【全景】夕阳/柔光下的环境（氛围营造）
【移镜头→中景】两人互动、眼神交流（关系建立）
【缓慢推→特写】微笑/牵手/拥抱（情感落点）
【拉镜头→远景】温馨画面渐行渐远（余韵收尾）
```

**应用示例**：
```
【全景】夕阳西下，公园长椅上洒满金色（氛围营造）
【移镜头→中景】两人的影子慢慢靠近（关系递进）
【缓慢推→特写】手指触碰，没有收回（情感落点）
【拉镜头→远景】夕阳下的长椅背影渐远（余韵结尾）
```

|---------|------------|---------|---------|------|

### 3.3 高级镜头公式

#### 公式E：三推式情绪递进（适用于高潮戏）

```
第一次推镜：中景→近景 → 情绪开始升温
第二次推镜：近景→特写 → 情绪持续积累
第三次推镜：特写→大特写 → 情绪极致爆发
```

**应用场景**：告白场景、打脸高潮、真相揭露

#### 公式F：拉-推反差式（适用于反转/转折）

```
【拉镜头】从近景拉到全景 → 揭示环境/局势变化
【快速推】从全景推到特写 → 聚焦角色情绪反应
```

**应用场景**：身份揭露、局势反转、意外真相

#### 公式G：摇-跟-推三连（适用于追踪/搜寻）

```
【摇镜头】扫描环境 → 搜索/寻找
【跟镜头】跟随目标移动 → 持续追踪
【推镜头】捕捉目标特写 → 确认/发现
```

**应用场景**：搜寻、追逐、暗中观察

#### 公式H：固定-摇-固定反差（适用于对峙/谈判）

```
【固定镜头】中景 → 双方对峙静止
【摇镜头】缓慢从A摇到B → 展示关系/对比
【固定镜头】特写 → 关键对话/情绪落点
```

**应用场景**：对峙、谈判、情感告白

### 3.4 情绪曲线联动公式

> 将镜头组合与情绪强度曲线对齐，在同一时间线上规划镜头使用。

| 情绪曲线位置 | 情绪强度 | 推荐镜头组合 | 功能 |
|------------|---------|------------|------|
| **开场钩子（0-3秒）** | 4-5级 | 特写+推镜头/晃镜头 | 瞬间抓住注意力 |
| **情境建立（3-15秒）** | 2-3级 | 全景/中景+固定/缓慢移 | 交代环境与关系 |
| **情绪升级（15-50秒）** | 3→4→5级 ↑ | 中景→近景→特写+推镜头 | 情绪逐步积累 |
| **高潮爆发（50-55秒）** | 5级 | 特写/大特写+快速推+晃镜头 | 情绪极致释放 |
| **结尾钩子（55-60秒）** | 5级 | 特写+推镜头+定格 | 留下悬念/追更驱动 |

## 4. 创作心法（V2.1.0 NEW）【创作必用】

> 以下4条心法是镜头语言创作的底层逻辑，所有剧本创作和分镜设计必须遵循。

### 心法一：先定情绪再选镜头

**核心要义**：镜头语言是情绪的视觉化表达，情绪决定镜头，而非镜头决定情绪。

**执行标准**：
- 每个场景必须先明确核心情绪目标（爽/虐/甜/燃/恐/悲）
- 根据情绪强度等级（1-5级）选择对应景别序列
- 情绪类型决定运镜方式：爽感用快速推/拉，虐感用缓慢拉/固定，甜感用缓慢推/移，燃感用快速切/晃
- 禁止先选镜头再套情绪，禁止为炫技而使用复杂运镜

**速查口诀**：情绪是根，镜头是叶；根不深，叶不茂。

### 心法二：动静结合才有呼吸

**核心要义**：节奏的张弛有度是观众持续观看的关键，全篇同一节奏会导致审美疲劳。

**执行标准**：
- 激昂场景中必须插入至少1个静默长镜（3-5秒固定镜头）
- 安静场景中必须预埋1个动态镜头（推/拉/移）作为情绪转折点
- 公式：动（2-3镜）+ 静（1镜）+ 动（2-3镜）= 最佳节奏曲线
- 情绪5级爆发点前，必须有2-3秒的慢节奏铺垫（蓄势）
- 禁止连续5个以上快节奏镜头，禁止连续3个以上慢节奏镜头

**速查口诀**：一张一弛，文武之道；一快一慢，观众不烦。

### 心法三：竖屏优先原则

**核心要义**：AI短剧以竖屏9:16为主要播放格式，所有镜头设计必须以竖屏效果为首要考量。

**执行标准**：
- 纵向运动（升降/俯仰/Z轴纵深）优先于横向运动（横摇/横移）
- 近景+特写占比必须≥70%，全景占比≤10%，远景尽量不用
- 双人对话采用上下排列，禁止左右并排导致画面过挤
- 人物面部居中偏上，占据画面40-60%，预留底部字幕安全区
- 优先选择竖屏适配度"高"的镜头技巧，慎用"中"，禁用"低"

**速查口诀**：竖屏为王，纵向为皇；人脸居中，字幕留空。

### 心法四：AI提示词架构规范

**核心要义**：给AI生成分镜画面时，提示词必须遵循标准化架构，确保生成效果可控、可复现。

**执行标准**：
- 提示词标准格式：`[镜头类型] + [运动方式] + [情感关键词] + [风格修饰]`
- 必须包含竖屏参数：`--ar 9:16`（Midjourney）或 `Size: 1088x1920`（SD）
- 情感关键词必须具体化：不用"悲伤"，用"眼泪滑落+肩膀颤抖+眼神空洞"
- 质量词必须前置：`(best quality, 8k, masterpiece)` 作为正向提示词开头
- 负面提示词必须包含：`deformed, bad anatomy, extra limb, blurry`
- 每个分镜必须标注AI生成难度和预估时间

**速查口诀**：类型运动情感风，竖屏参数不能忘；质量前置负面防，难度时间要标注。

## 5. 竖屏特殊镜头（V2.1.0 NEW）【创作必用】

> 以下4个竖屏专属镜头技巧，充分利用9:16画幅的纵向优势，是竖屏短剧的核心竞争力。

| 技巧名称 | 竖屏适配度 | AI生成难度 | 适用场景 | 效果描述 |
|---------|-----------|-----------|---------|---------|
| **垂直升降** | 高 | 低 | 登场亮相、上下打量、地位揭示 | 垂直方向上下移动，完美适配竖屏9:16画幅，展现身高差或地位差，营造气势感 |
| **Z轴纵深** | 高 | 中 | 走廊追逐、深邃空间、纵深探索 | 沿镜头光轴方向纵深运动，利用竖屏纵向深度营造空间穿透感，增强画面层次 |
| **对角线移动** | 高 | 中 | 战斗追逐、动态入场、冲突推进 | 沿画面对角线方向移动，增强动感和张力，打破竖屏纵向局限，让画面更活跃 |
| **爬升仰视** | 高 | 中 | 英雄登场、气势崛起、力量展示 | 从低处向上抬升镜头，配合仰视角度，强化崇高感和力量感，竖屏纵向空间完美承载 |

**竖屏特殊镜头组合公式**：

```
【英雄登场公式】爬升仰视 + 垂直升降 + 推进亲密
效果：从低角度仰拍角色，镜头缓缓上升并推向面部，营造气势与亲近感并存

【追逐紧张公式】Z轴纵深 + 手持灵动 + 对角线移动
效果：沿纵深方向追逐，手持晃动增强真实感，对角线打破单调，三重叠加制造极致紧张

【地位揭示公式】垂直升降 + 压迫俯拍/无力仰角
效果：升降展示身高/地位差异，配合俯拍或仰角强化权力关系，一升一降间关系立现
```

## 6. 竖屏适配特殊规则

> AI短剧以竖屏（9:16）为主要播放格式，镜头语言需特别适配。

### 4.1 竖屏景别调整

| 景别 | 竖屏表现 | 使用建议 |
|------|---------|---------|
| **大特写** | 效果极佳，满屏冲击 | 情绪爆发首选 |
| **特写** | 效果优秀，面部占主导 | 对话/情绪核心镜头 |
| **近景** | 效果良好，兼顾表情和小动作 | 常规对话主力镜头 |
| **中景** | 效果一般，人物偏小 | 适度使用，配合动作 |
| **全景** | 效果差，人物太小 | 仅在必要时使用，且不超过3秒 |
| **远景** | 效果极差 | 不建议使用 |

### 4.2 竖屏运镜调整

- **推镜头**：纵向推进效果更好（直接推向面部）
- **摇镜头**：水平摇动范围受限，建议小幅度
- **移镜头**：横向移动需放慢速度
- **跟镜头**：纵向跟拍（前后跟）> 横向跟拍（左右跟）
- **升/降镜头**：竖屏表现力极佳，建议多用

### 4.3 竖屏构图原则

```
┌─────────────┐
│  上方留空区   │  ← 文字/弹幕区域
│   (字幕预留)  │
├─────────────┤
│             │
│  主体区域    │  ← 主要视觉内容（人物面部/核心道具）
│  (核心焦点)  │
│             │
├─────────────┤
│  下方留空区   │  ← 字幕/包装区域
│   (字幕预留)  │
└─────────────┘
```

- **核心视觉**：人物面部居中偏上，占据画面40-60%
- **字幕预留**：底部安全区（约15%画面高度）
- **双人对话**：上下排列（非横排），避免左右并排导致画面过挤
- **近景占比**：近景+特写占比≥70%，全景占比≤10%
