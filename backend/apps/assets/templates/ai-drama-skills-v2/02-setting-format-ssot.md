# 02_项目设定 格式 SSOT

> 创作期三文件 **固定文件名** + **固定结构**；`03_完整剧本/` 见 `templates/natural-script-standard.md`。

## 文件清单

| 路径 | 一级标题 |
|------|----------|
| `02_项目设定/世界观设定.md` | `# 世界观设定` |
| `02_项目设定/人物小传.md` | `# 人物小传` |
| `02_项目设定/分集大纲.md` | `# 分集大纲` |

校验：`npm run verify-format -- --project-dir=项目根`

---

## 1. 世界观设定.md

```markdown
# 世界观设定

## 时代与地域
- **时代**：[现代都市 / 古代架空 / …]
- **地域**：[主要发生地]

## 核心设定
[1–2 段：权力结构、规则、核心矛盾环境]

## 风格元素
[关键词，顿号分隔]

## 核心亮点
- [亮点1]
- [亮点2]
```

## 2. 人物小传.md

每个有名角色一节：`## 角色名（定位）`

```markdown
# 人物小传

## 林晚（女主）
- **年龄**：[年龄]
- **定位**：主角 · [一句话定位]
- **性格**：[表面] / [内核]
- **音色**：冷感御姐音（音高中 · 语速中偏慢 · AI配音参考）
- **背景**：[身份、关系、核心动机，1 段]
- **S级标志性动作**：[动作] — [象征意义]

## 陆沉（男主）
- **音色**：低沉磁性男中音（音高偏低 · 语速中偏慢 · AI配音参考）
…
```

> 反派可加「施害者洗白风险预防」子列表（见 `expansion-rules.md` 第三板块）。

---

## 3. 分集大纲.md

```markdown
# 分集大纲

## 第1集：入职冲突
- **场景**：[地点] · [时间] · [氛围]
- **作者设计情绪强度**：3→2→4→5
- **核心道具**：[道具] — [功能]
- **黄金金句**：「……」（[位置]）
- **剧情要点**：[2–4 句]
- **结尾钩子**：[1–2 句]
- **付费/卡点设计**（≥30 集）：`【付费卡点】` 等 **仅写此处**，禁止进 03

## 第2集：……
```

> 情绪强度 / 金句 / 道具 **只写大纲**，禁止写入 `03_完整剧本/`。

## 4. 03 剧本场头（交叉引用）

**唯一合法场头**：`集号-镜头号 时间 内外 地点`（详见 `templates/natural-script-standard.md` §1–§9）

```
1-1 日 内 林家客厅
人物：林晚、陆沉

△【全景】……
林晚（冷淡）：……
林晚OS：……
【转场】切至：客厅→走廊
【音效】脚步声渐近
```

**允许**：`△【景别】`、`【闪回开始/结束】`、`【转场】`、`【音效】`（§3/§6–§9）  
**禁止**：无镜头号场头、方括号【场景】场头、独立【画面】/【镜头】行、workflow 设计块（`【付费卡点】`/`【悬念钩子】` 等）、对白行外加引号。
