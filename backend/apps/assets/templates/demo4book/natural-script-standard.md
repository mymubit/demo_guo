# AI短剧自然化剧本规范模板 v1.1

> **使用说明**：本模板为AI短剧剧本创作提供对白自然化、镜头流畅化、结构多样化的统一规范。所有技能在生成/优化剧本时应引用此模板。
> **v1.1更新**：新增商业剧本格式规范，统一行业标准格式。

---

## 商业剧本格式规范（v1.1新增）

### 格式总览

本规范定义AI短剧商业标准剧本格式，所有技能生成的剧本必须遵循以下格式规范。

### 1. 场景头格式

**标准格式**：`集号-镜头号 时间 内外 地点`

| 元素 | 格式 | 示例 |
|------|------|------|
| 集号-镜头号 | 数字-数字 | `1-1`、`5-3` |
| 时间 | 日/夜/晨/昏 | `日`、`夜` |
| 内外 | 内/外 | `内`、`外` |
| 地点 | 具体场景名 | `朱雀门楼`、`出租屋` |

**正确示例**：
```
1-1 日 外 朱雀门楼
5-3 夜 内 出租屋
```

**禁止**：方括号场景头、无镜头号场头、独立 `【画面】`/`【镜头】` 行。

### 2. 人物列表

场景头后列出本场景所有人物。

**格式**：`人物：XXX、XXX、XXX（群）`

**示例**：
```
1-1 日 外 朱雀门楼
人物：夏倾凰、秦桧、侍卫（群）
```

### 3. 动作标记

使用 `△` 符号开头表示动作描述。

**格式**：`△【景别】动作描述`

**示例**：
```
△【全景】残阳如血，朱雀门楼上，夏倾凰的铠甲泛着冷光。
△【特写】她手指轻抚剑柄，眼神如冰。
```

**禁止**：括号景别、独立 `【画面】` 行；镜头写在 `△【景别】` 内。

### 4. 台词格式

**格式**：`角色（情绪）：台词`

**示例**：
```
秦桧（阴冷）：陛下，镇北王拥兵自重，此女断不可留。
夏倾凰（冷笑）：秦相国说的是你自己吧？
```

**错误示例**：
```
林晓雨：（轻声）"青山，你怕吗？"   ❌ 不使用引号，情绪在括号内
林晓雨（轻声）："青山，你怕吗？"   ❌ 不使用引号
```

### 4.0 创作期文件分离（硬约束）

| 路径 | 内容 |
|------|------|
| `02_项目设定/世界观设定.md` | 世界观 |
| `02_项目设定/人物小传.md` | 人设（含音色） |
| `02_项目设定/分集大纲.md` | 集纲、情绪曲线、金句、道具标注 |
| `03_完整剧本/*.md` | **仅纯剧本**（扩写/润色/verify 对象） |
| `《剧名》交付包.md` | 完本 `pack-delivery`：02 三块 + 03 剧本合并 |

创作期 `verify-script` / `check-episode` 只校验 `03` 纯剧本；设定板块误入剧本将失败。

### 4.1 台词密度（创作 + 交付 SSOT）

| 项 | 标准 |
|----|------|
| 台词占比 | 单集 **≥28%**（台词 CJK ÷ **纯剧本** CJK） |
| 计入口径 | `角色（情绪）：台词` 与 `角色os：` 冒号后正文 |
| 不计入 | 场戏头、`人物：`、纯 △ 动作；AI 提示词/润色报告块；`【潜台词】`；集级统计行；作者设计标注行 |
| 禁止写入 `03_完整剧本/` | 上述元数据 → 情绪曲线/金句/道具写 **分集大纲**；AI 绘图提示词 → `production-visual` → `06_制作物料/` |
| 折算下限 | 第1集纯剧本 900–1100 时，台词 ≥**252** 字；第2集起 700–900 时，台词 ≥**196** 字 |
| 扩写原则 | **优先加对白/os**，勿用超长 △ 或说明段凑字数 |

SSOT：`config/skill-thresholds.json#outputCompleteness` · 创作摘要 `formatCreationDeliveryRules()` · 交付 `verify-script`

### 5. OS标记（内心独白）

**格式**：`角色OS：内容`

**示例**：
```
夏倾凰OS：（心如死灰）我的兵，我的国……
```

### 6. 镜头标记

使用 `【特写】【全景】【近景】【中景】` 等，放在动作描述中，不是单独一行。

**示例**：
```
△【全景】朝堂之上，文武百官分列两侧。
△【推镜头】从全景缓缓推至夏倾凰面部【特写】。
```

### 7. 闪回标记

**格式**：
```
【闪回开始】
...闪回内容...
【闪回结束】
```

### 8. 转场标记

**格式**：`【转场】转场类型`

**示例**：
```
【转场】动作匹配：关门（场景A）→开门（场景B）
【转场】视线：女主看窗外→窗外景象
```

### 9. 音效标记

**格式**：`【音效】音效描述`

**示例**：
```
【音效】战鼓雷鸣
【音效】刀剑出鞘的金属摩擦声
```

### 10. 完整格式示例

```
第1集：重生归来

> 情绪曲线、黄金金句、核心道具等设计标注写在 **分集大纲**，不进完整剧本正文。

1-1 日 外 朱雀门楼
人物：夏倾凰、秦桧、侍卫（群）

△【全景】残阳如血，朱雀门楼上，夏倾凰的铠甲泛着冷光。
△【特写】她手指轻抚剑柄，眼神如冰。

夏倾凰（冷笑）：秦相国说的是你自己吧？

△【推镜头】从秦桧惊恐的脸【特写】缓缓拉至夏倾凰决绝的背影【全景】。

夏倾凰OS：（心如死灰）我的兵，我的国……

【音效】战鼓雷鸣

1-2 夜 内 天牢

【闪回开始】

【闪回结束】

△【特写】夏倾凰攥紧拳头，指甲嵌入掌心。
```

## 一、对白自然度规范

### 1.1 口语化特征清单

| 特征 | 标记方式 | 示例 |
|-----|---------|------|
| **停顿** | `...` 或 `——` | "那个...我想说的是..." |
| **打断** | `（打断）` | 男主：（打断）"别说了！" |
| **重叠** | `（同时）` | 女主：（同时）"你听我说！" |
| **重复强调** | 重复关键词 | "为什么...为什么是你！" |
| **语法不完整** | 允许断句 | "这事吧，怎么说呢..." |

### 1.2 口头禅配置表

每个角色必须配置2-3个口头禅：

```yaml
角色口头禅配置：
  女主_林婉儿：
    - "你爸呢！"
    - "冷静冷静，我们来分析一下"
    - "说白了..."
  
  男主_冷面王爷：
    - "放肆！"
    - "本王..."
    - "哼"
```

### 1.3 去AI腔禁用词表

| 禁用词（书面语） | 替换词（口语） |
|----------------|--------------|
| 让我们 | 咱们 / 咱 |
| 我认为 | 我觉得 / 我看 |
| 事实上 | 说实话 / 说白了 |
| 然而 | 但是 / 不过 |
| 因此 | 所以 / 那 |
| 综上所述 | 总之 / 说白了 |
| 请问 | （直接问） |
| 非常 | 挺 / 怪 / 老 |

### 1.4 潜台词标注规范

潜台词设计写在 **`02_项目设定/分集大纲.md`** 或 **`04_评估报告/润色报告.md`**，**不进** `03_完整剧本/`（不计入 verify 字数）。

大纲示例：

```
第8集 · 林晚「没关系」→ 潜台词：我恨你，我在演
```

### 1.5 对话节奏与情绪匹配

| 情绪强度 | 对话特征 | 句式特点 | 示例 |
|---------|---------|---------|------|
| 1-2级（平静） | 正常语速 | 完整句子，15-20字 | "今天天气不错。" |
| 3级（波动） | 开始变短 | 有停顿，10-15字 | "那个...我想..." |
| 4级（强烈） | 短句为主 | 打断抢话，5-10字 | "你！——" "听我说！" |
| 5级（爆发） | 断断续续 | 词语重复，2-5字 | "为什么...为什么！" |

## 二、镜头语言规范

### 2.1 转场类型表

| 转场类型 | 标记方式 | 适用场景 | 示例 |
|---------|---------|---------|------|
| **动作匹配** | `【转场】动作匹配` | 相似动作衔接 | 关门→开门 |
| **视线转场** | `【转场】视线` | 角色看向某处 | 女主看窗外→窗外景象 |
| **声音先入** | `【转场】声音先入` | 先听后看 | 争吵声→客厅场景 |
| **相似体** | `【转场】相似体` | 形状/颜色相似 | 酒杯→月亮 |
| **情绪转场** | `【转场】情绪` | 情绪延续 | 愤怒表情→摔门而去 |

### 2.2 景别与情绪匹配

| 情绪强度 | 推荐景别序列 | 运镜建议 |
|---------|------------|---------|
| 1-2级 | 全景→中景 | 固定或缓慢横移 |
| 3级 | 中景→近景 | 轻微推镜头 |
| 4级 | 近景→特写 | 推镜头+轻微晃动 |
| 5级 | 特写→大特写→特写 | 快速推+定格 |

### 2.3 运镜方式与情绪效果

| 运镜 | 情绪效果 | 适用场景 |
|-----|---------|---------|
| **推** | 紧张感、逼近真相 | 发现秘密、对峙 |
| **拉** | 疏离感、揭示环境 | 离别、孤独 |
| **摇** | 不安感、寻找目标 | 搜索、疑惑 |
| **移** | 流动感、跟随角色 | 行走、追逐 |
| **跟** | 紧迫感、持续追踪 | 逃跑、追踪 |

### 2.4 镜头标注格式（写在 △ 行内）

```
△【特写】女主颤抖的手
△【推镜头】从全景缓缓推至女主面部
△【跟镜头】跟随男主奔跑
【转场】视线：女主看窗外→窗外景象
```

> **禁止**独立 `【镜头】景别：描述` 行；镜头写在 `△【景别】` 内。非标准稿用 `npm run normalize-script` 清洗。

## 三、剧本结构多样性规范

### 3.1 开场方式库

> `【开场】*` 类型标注仅写**分集大纲**；03 正文用下表「03 示例」场戏表达。

| 开场方式 | 大纲标记（可选） | 适用场景 | 03 示例 |
|---------|----------------|---------|---------|
| **动作先行** | 动作型 | 紧张/冲突 | △摔门声，女主冲进房间 |
| **声音先行** | 声音型 | 悬念/对话 | 女主（颤抖）：我受够了！ |
| **对话打断** | 对话型 | 情感/冲突 | 女主：……所以你一直在骗我？ |
| **主观视角** | 主观型 | 内心/体验 | △【主观视角】模糊的视线 |
| **闪回开场** | 闪回型 | 回忆/揭秘 | 【闪回开始】…【闪回结束】 |
| **物品特写** | 物品型 | 悬疑/情感 | △【特写】一封泛黄的信 |
| **环境氛围** | 环境型 | 氛围/情绪 | △【全景】暴雨中的街道 |

### 3.2 叙事视角规范

| 视角类型 | 标记方式 | 特点 | 适用场景 |
|---------|---------|------|---------|
| 客观视角 | （默认） | 第三人称，全知 | 常规叙事 |
| 主观视角 | `【视角】主观` | 角色视角 | 悬疑、体验场景 |
| 限制视角 | `【视角】限制` | 观众知情角色不知 | 悬念、反转前 |
| 全知视角 | `【视角】全知` | 展示多角色内心 | 情感交织场景 |

### 3.3 时间线处理

| 时间线类型 | 标记方式 | 适用场景 |
|-----------|---------|---------|
| 线性叙事 | （默认） | 常规剧情 |
| 倒叙开场 | `【倒叙】` | 悬疑、复仇 |
| 插叙 | `【闪回】` | 情感、揭秘 |
| 平行叙事 | `【平行】` | 多角色、对比 |

### 3.4 结构多样化检查清单

- [ ] 全剧使用≥3种不同开场方式
- [ ] 相邻集数开场方式不重复
- [ ] 情绪高点使用主观视角或特写开场
- [ ] 悬念场景使用限制视角
- [ ] 回忆场景明确标注【闪回】
- [ ] 每5集至少使用1次非客观视角

## 四、四段式结构规范

四段式结构是AI短剧单集剧本的核心叙事框架，所有技能在生成/优化单集剧本时必须遵循此规范。

### 4.1 四段式结构定义

| 段落 | 时间范围 | 核心功能 | 情绪强度 | 内容要求 |
|-----|---------|---------|---------|---------|
| **强开场钩子** | 0-3秒 | 抓住注意力 | 3-4级 | 冲突/悬念/反转/危机/金句/视觉冲击，确保用户不划走 |
| **情境建立** | 3-15秒 | 交代背景 | 2-4级 | 快速建立场景、人物关系、核心矛盾 |
| **情绪升级** | 15-60秒 | 推进剧情 | 持续升级 | 每15秒一个情绪转折点，冲突升级、情感递进 |
| **结尾悬念钩子** | 50-60秒（最后10秒） | 留住用户 | 5级峰值 | 强反转/悬念/冲突，禁止完整收束，引导追更 |

**时间范围说明**：
- 四段时间总和为60秒（1分钟标准短剧）
- 情绪升级（15-60秒）跨越整个中段，共计45秒，是剧情推进的主要段落
- 结尾悬念钩子位于50-60秒区间，即整个视频的最后10秒
- 时间节点：开场钩子(0-3s) → 情境建立(3-15s) → 情绪升级(15-60s) → 结尾悬念(50-60s)

### 4.2 6种开场钩子类型

| 类型 | 说明 | 适用场景 | 情绪强度 |
|-----|------|---------|---------|
| **视觉冲击型** | 震撼画面/奇观/极端场景 | 动作、特效、大场面 | 4级 |
| **悬念型** | 抛出未解之谜 | 悬疑、推理、玄幻 | 3级 |
| **冲突爆发型** | 直接呈现激烈冲突 | 虐恋、复仇、宫斗 | 4-5级 |
| **金句型** | 金句/炸裂台词开场 | 所有类型 | 3-4级 |
| **反转型** | 颠覆预期认知 | 甜宠、逆袭、重生 | 4-5级 |
| **危机型** | 生死存亡的紧迫感 | 动作、灾难、求生 | 4级 |

### 4.3 5种结尾钩子类型

| 类型 | 说明 | 悬念强度 | 效果 |
|-----|------|---------|------|
| **悬念型** | 留下未解之谜 | ★★★★★ | 强烈追更欲望 |
| **反转型** | 剧情突然转折 | ★★★★★ | 意外感 |
| **冲突升级型** | 矛盾激化 | ★★★★☆ | 紧张感 |
| **情感爆发型** | 情绪顶点 | ★★★★☆ | 共鸣感 |
| **危机降临型** | 危险/威胁出现 | ★★★★★ | 紧迫感 |

### 4.4 使用说明
