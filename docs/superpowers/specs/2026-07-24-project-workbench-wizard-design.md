# 单项目创作向导工作台 — 设计

> 日期：2026-07-24  
> 状态：已确认  
> 范围档：方案 2（整页向导重构）+ 产物预览 C（可读 + 原始 JSON）

## 1. 目标

把「仪表盘 → 概览 → 再进阶段」收成：**仪表盘选项目 → 当前阶段工作台**；阶段切换在左轨完成；产物默认可读预览，可切原始 JSON。

## 2. 信息架构

| 路由 | 职责 |
|------|------|
| `/dashboard` | 项目入口（列表/看板）；建项、搜索、归档/删除 |
| `/projects/:id/*` | 单项目创作向导工作台 |
| `/projects/:id` | 重定向到当前 `stage` 对应子路径 |
| `/projects/:id/settings` | 原概览能力（回滚、归档入口等），不挡主流程 |
| 子路径 | `topic` / `blueprint` / `episodes` / `editor` / `quality` / `delivery` |

点项目卡片：**主链接直达当前阶段**（非 settings）。

## 3. 工作台布局

```
┌──────────┬─────────────────────────────┐
│ 阶段左轨  │ 顶栏：标题 · 上一步/下一步 · 设置 │
│ 六步步进  ├─────────────────────────────┤
│          │ Outlet：阶段页内容            │
│          │ （W2 起右侧可挂产物预览）      │
└──────────┴─────────────────────────────┘
```

- **左轨**：六阶段；当前高亮；已完成可点；未达阶段可只读进入（写操作仍受后端门禁）
- **顶栏**：项目标题、上一步/下一步、链到 settings
- **中栏**：现有阶段页迁入 Outlet（去掉重复的全页「当前阶段」噪音可渐进）

## 4. 产物预览（W2）

共用 `ArtifactPreview`：
- 默认：结构化可读（复用/扩展 `artifactDisplay`）
- 切换：原始 JSON（缩进 + mono；可选轻量高亮，不强制新依赖）

接入：Topic / Blueprint / Episodes / Delivery 等「详细内容」替换裸 `<pre>`。

## 5. 分期

| 波次 | 交付 | 验收要点 |
|------|------|----------|
| **W1** | Workbench 壳 + 嵌套路由 + 卡片直达阶段 + 概览→settings | 打开项目落在当前阶段；左轨可切换；settings 可回滚 |
| **W2** | `ArtifactPreview` 全阶段 | 默认可读，可切 JSON |
| **W3** | 阶段页操作流打磨 | 生成态/确认/下一步门禁文案统一 |

## 6. 不在范围

- 后端 stage 状态机重写、拖拽改 stage、支付/配额、新依赖（除非 W2 明确需要）

## 7. 自检

- 无占位符；与现有 stage 枚举、子路径对齐  
- W1 不依赖 W2 预览即可独立可用  
- 创作者 UI 仍不暴露 operation/recipe ID
