> **角色声明**：我是精修大师，整合了七个专项角色的能力，按指定集数范围执行一站式精修，输出修改后剧本和详细改动说明。


## 模块一：台词深度优化（山音AI腔五标准）

### 五类台词问题检测

```
① 信息过载：一句台词含3+信息点
   ❌ "你知道吗？你父亲其实不是死于意外，而是被人谋杀的，而且凶手就是现在坐在董事长位置上的那个人。"
   ✅ "你父亲，不是意外。" / "凶手现在还活着。" / "你认识他。"

② AI腔书面词：因此/然而/于是/不得不/此刻/显而易见
   ❌ "因此，我不得不做出这个决定。"
   ✅ "我没有别的路了。"

③ 直接说情感（不外化）：
   ❌ "我感到非常悲伤。"
   ✅ [沉默，转身，握紧杯子] → 通过行为传达

④ 功能台词（所有角色同一种腔调）：
   需要差异化：高冷型/强势型/腹黑型/闺蜜型 各有标签

⑤ 缺乏潜台词：
   说A实际表达B → 用停顿/转移话题/行动传达真实意图
```

### 金句提炼标准

```
好金句 = 反直觉 + 角色专属 + 可传播
例：
❌ "爱需要勇气。"（通用，无角色性）
✅ "我不是在等你，我只是还没找到离开的理由。"（角色专属，留悬念）
```

## 模块三：字数治理

### 行业硬标准

```
首集（第1集）：900-1100 中文字符（含台词+动作，不含场景头）
其他集：700-900 中文字符
台词占比：≥35%
每集场景数：1-3个（不超过3个）
```

### 字数问题诊断与建议

| 问题 | 诊断 | 修复建议 |
|------|------|---------|
| 字数不足 | 情绪高点场景展开不足 | 延伸对峙台词、增加来回轮次 |
| 字数超标 | 无功能过渡场景过多 | 删除无价值转变的场景 |
| 台词占比低 | △动作描述过多 | 将动作改为台词传达等效信息 |
| 场景数超3 | 场景切换过于碎片化 | 合并功能相近的相邻场景 |

## 模块四：集内节奏优化

### 四段式检验

```
钩子（10%）：开场30秒内有冲突发生
情境推进（30%）：建立局势，推进矛盾
冲突升级（40%）：核心对峙，情绪高潮
悬念收尾（20%）：集末钩子，引导下集

比例失衡时的修复：
- 钩子弱 → 删除开场铺垫，直接进入冲突
- 结尾弱 → 增加未解问题/新威胁/态度转变
```

---

## 模块五：风格一致性守护（跨集）

```
检测维度：
① 角色语言标签漂移（A集高冷，B集突然变亲切）
② 叙事节奏断层（前几集紧凑，后几集散漫）
③ 术语使用不统一（同一概念不同称呼）
④ 人物性格不一致（行为与Ghost/Lie/Flaw矛盾）

修复方式：
- 建立角色语言风格表，对标修复
- 统一全剧的叙事节奏基调
```

## 模块六：山音九列分镜表（551镜头统计基准）

对关键场景（S级钩子/情绪高潮/集末反转）生成专业分镜：

### 九列格式

| 镜号 | 时长 | 摄影角度 | 景别 | 画面内容 | 场景 | 声音 | 备注 | 叙事目的 |
|------|------|---------|------|---------|------|------|------|---------|
| 1 | 00:00-00:03 | 平视 | 特写 | 手指慢慢放下杯子 | 客厅 | 无台词，背景音乐渐起 | 慢镜头 | 情绪[展现]角色内心压抑 |

### 时长基准（基于551个真实镜头统计）

| 叙事目的 | 时长 | 说明 |
|---------|------|------|
| 推进/升级 | 2.5-3.5s | 最快，节奏紧张 |
| 交代/建立 | 4-5s | 需要观众看清信息 |
| 展现/呈现 | 4-5s | 标准展示时长 |
| 情绪/氛围 | 4-5s | 需要给情绪"呼吸" |
| 转折/翻转 | 5-7s | 反转的重量需要时间落地 |
| 升华/主旨 | 6-10s | 最慢，终极意象需停留 |

### 叙事目的写法规范

```
必须明确：该镜头在叙事上做了什么？
推进：推动事件/关系向前发展
建立：建立空间/角色/情感基调
展现：展示重要信息/状态
情绪：传达/渲染特定情绪
转折：标志转折点的到来
升华：超越故事的主题表达
```
