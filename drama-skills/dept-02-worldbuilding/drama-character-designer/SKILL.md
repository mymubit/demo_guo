## 山音完整人物设计框架

### 第一层：Want vs Need（表面欲望 vs 深层需求）

```
Want（表层欲望）：角色自己知道的目标，主动追求的
Need（内在欲望）：角色灵魂的真正缺口，自己未曾意识到的

张力公式：Want ≠ Need → 这就是弧光的发动机

例：
Want = 复仇/升职/赢回他
Need = 学会接受自己的不完美/信任他人/活在当下

好角色的Want和Need必须在某个时刻产生直接冲突：
当追求Want的行为阻止了Need的满足 → 最高张力点
```

### 第二层：Ghost / Lie / Flaw（深度层 — 弧光必须）

```
Ghost（前史创伤）：
过去一件具体的事，至今影响角色所有行为。
作用：解释了为什么有这个Want，为什么看不见自己的Need。
必须是具体事件，不是模糊描述。
❌ "她从小受到了创伤" （太模糊）
✅ "7岁时，她目睹父亲为了保护她的继母，当众羞辱了她，
     而她最信任的母亲转身离开，从不回头。" （具体，有情绪）

Lie（角色相信的谎言）：
因Ghost形成的错误世界观/信念体系。
这不是坏人，是受伤的人。
例：
"我不能信任任何人，否则必然被背叛"
"只有强者才值得被爱，弱者活该被抛弃"
"爱 = 牺牲，我的痛苦是爱的代价"

Flaw（性格缺陷）：
由Lie引发的、在剧中导致问题的行为模式。
弧光 = 角色在某个关键节点从Lie中醒来，接受真相（Truth）。

弧光完整结构：
Ghost → Lie → Flaw → [触发事件] → 认识Truth → 行为改变
```

### 第三层：矛盾性（好角色必须有至少一层）

```
矛盾性设计（选一种）：
外在强大 vs 内在脆弱
表面冷漠 vs 内心渴望连接
说恨 vs 行为表现出的爱
高傲 vs 对认可的渴望
理性 vs 行动时的冲动

矛盾性的作用：制造层次感，让观众持续想探索这个角色
写作提示：角色的行为和语言可以矛盾，让观众去猜真实的内心
```

## 关系网络设计原则

```
规模约束：
主角 ≤ 2人（否则情感投入被稀释）
核心配角 2-4人
总上限 6个需要记忆关系的角色

关系设计原则：
1. 所有关系都基于Lie的冲突设计
   反派的Lie 往往是主角Lie的镜像（相同扭曲，不同方向）
   
2. 关系不是静态的
   开始的立场 ≠ 结束的立场（关系弧光）

3. 每段关系都要有"信息不对称"
   至少有一方不知道对方的Ghost（便于后续揭露/反转）

关系网络图：
[主角] ←→ [配角A]：[关系类型+Lie冲突说明]
[主角] ←→ [反派]：[Lie的镜像关系]
[配角A] ←→ [反派]：[...]
```

## 梦境三指标深度检测（内嵌，人设完成后执行）

> 原 `drama-dream-analyst` 核心能力。人设设计完成后立即执行，**安全感 < 7 阻断后续创作**。

### 检测标准

**安全感（0-10，< 7 触发熔断）**
- 主角所有行为可以用「自卫/正义/保护」解释？
- 反派是否有 ≥ 3 个明确恶行？
- 是否存在主角做了残忍行为但剧情美化？

**满足感密度（基准值 > 0.8/集）**
```
满足感密度 = (爽点 + 甜点 + 强悬念点) / 总集数
```
- 付费卡点是否每 3 集有 S/A 级？
- 第一集主角是否展现「被压制但有能力」？

**真实感（0-10）**
- 核心矛盾（感情/钱/权力/家庭）是否接地气？
- 人物面对困境的第一反应是否符合普通人本能？
