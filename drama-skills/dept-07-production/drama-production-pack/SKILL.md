# 制作发行师（Drama Production Pack）

> **角色声明**：我是制作发行师，整合了五个制作专项角色，输出完整的制作发行物料包。可选输出 Story-to-Game 互动游戏衍生品。

## 触发方式

```
@drama-production-pack 生成第1-10集的制作物料
@drama-production-pack [分镜] 为S级反转场景生成九列分镜
@drama-production-pack [营销] 生成抖音投流文案
@drama-production-pack [game] 将剧本主线转化为互动游戏
@drama-production-pack [交付] 验证交付清单并生成交付包
```

---

## 物料一：角色视觉锚点

### 竖屏9:16设计约束

```
单镜头时长：3-8秒
字幕安全区：下方25%区域
主体位置：居中，视觉重心在画面上2/3
避免：左右构图、多人平铺（竖屏空间浪费）
```

### 角色视觉标识设计

```markdown
## 角色视觉档案：[角色名]

**视觉锚点**
- 服装标识：[标志性服装元素]
- 发型特征：[发型/颜色]
- 标志性物件：[随身物件，用于识别]
- 标志性姿态：[站姿/表情]

**AI图像 Prompt（正面）**
[角色名], [服装描述], [发型], [情绪表达], 竖屏肖像, 电影质感

**AI视频 Prompt（关键场景）**
[景别], [角色+动作+情绪], [光线风格], [镜头运动], 竖屏9:16
```

## 物料三：配音情绪脚本

```
台词标注格式：
[语速：快/中/慢] [音色：浑厚/明亮/沙哑/柔和] [情绪强度：1-5]
台词内容

字幕规范：
- 每行≤18个中文字符
- 断句在逻辑停顿处（不在词语中间断开）
- 叠词/拟声词保持完整
```

## 物料四：营销文案包（平台差异化）

### 抖音版（前3秒视觉冲击优先）

```markdown
## 抖音标题（三个版本）

A版（悬念型）：[15字以内，以问号/省略号结尾]
B版（反转型）：[强调意外感，"没想到..."]
C版（爽感型）：[主角逆袭/打脸时刻]

## 抖音投流短视频脚本（15秒）
0-3秒：[冲突画面/反差场景]
3-8秒：[情感勾连/受众代入点]
8-15秒：[悬念留白，引导刷到下一条]
```

### 快手版（情感认同优先）

```
强调情感共鸣，标题突出角色处境/情感困境
例："三年了，她终于开口了"
```

### 微信版（中年情感+稳定叙事）

```
强调故事性和情感厚度
例："一个被全家人抛弃的女人，如何找回自己"
```

## 物料五：交付验证 + Story-to-Game（可选）

### 交付清单验证

```
四项验证：
✓ 集数完整（总集数 = 实际已写集数）
✓ 字数达标率 ≥ 95%（各集均在700-1100字区间）
✓ 质量报告分数 ≥ 75分（grade≥B）
✓ 合规检测通过（无P0/P1级问题）

输出：《[剧名]》交付包.md（四项验证结果 + 资产清单）
```

### Story-to-Game 互动衍生品（山音工具链，可选）

将剧本主线转化为可玩的分支叙事游戏：

```
分支类型比例：
态度分支（40%）：选择角色对话态度/情绪
路径分支（35%）：选择行动方向
命运分支（25%）：决定关键节点结局

节点结构（JSON格式）：
{
  "id": "node_001",
  "scene": "场景描述",
  "dialogue": "当前台词",
  "choices": [
    {"text": "选项A", "next": "node_002", "effect": {"trust": +1}},
    {"text": "选项B", "next": "node_003", "effect": {"trust": -1}}
  ],
  "state_values": {"trust": 0, "power": 0}
}

13项自动校验：节点可达性/引用完整性/结局完整性...
```
