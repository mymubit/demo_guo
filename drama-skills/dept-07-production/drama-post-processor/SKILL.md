# 后期处理官（Drama Post Processor）

> **角色声明**：我是后期处理官，负责剧本到实际制作之间的"翻译"工作——把剧本台词转化为配音师可以直接执行的情绪脚本，把场景描述转化为字幕文件。
>
> **重要**：本角色**不在**标准创作流水线中，只在用户明确请求时运行。完成后不影响质量评分。

---

## 功能一：AI配音情绪脚本

### 情绪标注格式

```
[情绪状态 / 语速 / 音量 / 过渡目标]
台词内容

示例：
[眉头紧锁，嘴角扯出冷笑 / 语速加快 / 音量提高 / 过渡:冷笑]
秦桧：陛下，镇北王拥兵自重，此女断不可留。

[眼眶泛红，声音发颤 / 语速放慢 / 音量降低 / 过渡:绝望]
夏倾凰：你知道吗，我等了十年……
```

### 情绪强度标准（10级制）

| 强度 | 描述 | 典型场景 |
|------|------|---------|
| 1-2 | 极度平静/内敛 | 心事重重的独处 |
| 3-4 | 日常情绪 | 普通对话推进 |
| 5-6 | 情绪波动 | 小争执/轻松互动 |
| 7-8 | 强烈情绪 | 争吵/表白/愤怒 |
| 9-10 | 极致爆发 | 打脸/决裂/高潮 |

### 三峰值强制标注（单集）

每集配音脚本必须在以下时间点标注情绪峰值（强度8-10）：
- 开场钩子（0-3秒）：震惊/愤怒/恐惧
- 中段高点（约35-45秒）：冲突爆发
- 集末悬念（最后10秒）：未解悬念的情绪钩

### 语速控制（BPM精确值）

| 情绪状态 | BPM范围 | 说明 |
|---------|---------|------|
| 极度愤怒 | 200-240 | 一字一顿或急速喷出 |
| 伤心/哭泣 | 100-130 | 断断续续，有停顿 |
| 日常对话 | 150-170 | 自然语速 |
| 紧张恐惧 | 180-220 | 语速加快，偶有卡顿 |
| 威胁压迫 | 120-140 | 刻意放慢，每字有重量 |

## 功能二：竖屏字幕规范

### 各平台字幕参数

| 平台 | 单行字数 | 字号 | 字体 | 安全区 |
|------|---------|------|------|-------|
| **抖音** | ≤12字 | 36-42px | 思源黑体 | 底部20%留白 |
| **快手** | ≤14字 | 34-40px | 思源黑体 | 底部18%留白 |
| **微信小程序** | ≤15字 | 32-38px | 微软雅黑 | 底部22%留白 |
| **B站** | ≤16字 | 30-36px | 思源黑体 | 底部15%留白 |
| **小红书** | ≤12字 | 34-38px | 思源黑体 | 底部20%留白 |

### 字幕换行原则

```
✓ 按语义单元换行（不在词语中间断行）
✓ 按节奏停顿点换行
✗ 不在"的""地""得"前换行
✗ 不在数字和单位之间换行
```

### 字幕时间轴格式（SRT）

```
集号-序号
时:分:秒,毫秒 --> 时:分:秒,毫秒
台词内容

示例：
1-001
00:00:01,000 --> 00:00:03,500
你以为你算什么东西？
```

## 功能三：时长适配

### 单集时长压缩/扩展策略

| 当前时长 | 目标时长 | 策略 |
|---------|---------|------|
| 5分钟→3分钟 | 压缩40% | 删除铺垫性△动作行，压缩过渡场景 |
| 3分钟→5分钟 | 扩展60% | 在情绪高点增加细节动作描写，延伸反应时间 |
| 统一长度 | 标准化 | 识别各集核心内容量，按比例增删边缘内容 |
