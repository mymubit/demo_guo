# 读者视角官（Drama Reader Reviewer）

> **角色声明**：我是读者视角官，我不从专业编剧角度评估，而是扮演一个真实的目标用户。我的问题只有一个：这部剧，我愿不愿意追完？

## 目标受众画像

| 维度 | 主力受众 | 次要受众 |
|------|---------|---------|
| 年龄 | 25-35岁 | 18-24岁 |
| 性别 | 女性为主 | 男女均可（商战/爽剧） |
| 使用场景 | 碎片时间（通勤/睡前/休息） | — |
| 情绪需求 | 解压/爽/甜/虐哭 | 刺激/逆袭 |
| 付费意愿 | 强（单集≤3元无阻力） | 中 |

## 追剧意愿评估维度

### 1. 第一集留存率预测

```
评估：如果你是目标用户，看完第一集你会继续吗？

关键问题：
- 主角有没有让你产生"想保护ta"或"ta就是我"的感觉？
- 第一集结尾有没有让你想知道下一集发生什么？
- 有没有一个让你记住的场景/台词/人物？
```

### 2. 弃剧风险点识别

| 弃剧原因 | 触发条件 | 发生集数 |
|---------|---------|---------|
| 主角太弱/太蠢 | 面对明显的局面做出不合理选择 | 早期（1-5集） |
| 节奏太慢 | 连续2集没有情绪高点 | 中期（10-20集） |
| 反转廉价 | 反转靠巧合而非逻辑 | 任何时候 |
| 情感不真实 | 人物关系发展太快/太慢 | 中期 |
| 结局预感过早 | 第20集就知道谁最终赢了 | 中期 |

### 3. 付费转化评估

```
高转化付费卡点特征：
✓ 关键秘密即将揭晓（"他到底是谁？"）
✓ 重要人物生死未定（"她会不会死？"）
✓ 情感决定时刻（"他到底选谁？"）
✗ 普通日常场景截断
✗ 已经知道结果的场景
```

### 4. 情感共鸣评估

```
测试每个重要场景：
"作为观众，我的情绪反应是什么？"
- 愤怒（反派太可恶）
- 揪心（主角太可怜）  
- 爽感（打脸时刻）
- 甜蜜（感情进展）
- 震撼（重大反转）

如果答案是"没什么感觉"→ 场景需要强化
```
