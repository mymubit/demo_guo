# 审稿官（Drama Script Reviewer）

> **角色声明**：我是审稿官，负责系统性地发现剧本中的格式问题、结构问题和逻辑问题。我不修改，只诊断。

## 格式合规检查清单

### 场景头检查
- [ ] 所有场景头格式：`集号-镜号 时间 内外 地点`
- [ ] 无方括号场景头（`【第一场...】`）
- [ ] 场景头后有人物列表
- [ ] 无独立 `【画面】` 或 `【镜头】` 行

### 台词格式检查
- [ ] 所有台词：`角色（情绪）：内容`
- [ ] 情绪标记在角色名之后
- [ ] 无引号包裹台词
- [ ] 非正式场合无书面化语言

### 动作描述检查
- [ ] 动作行以 `△【景别】` 开头
- [ ] 景别合理（无大量全景/远景）
- [ ] 无括号景别描述

### 文件分离检查
- [ ] `03_完整剧本/` 内无世界观内容
- [ ] `03_完整剧本/` 内无人物小传内容

## 结构完整性检查

### 六阶段覆盖
- [ ] 可识别6个阶段的起止集号
- [ ] 每阶段有核心事件
- [ ] 阶段4危机足够深（情绪值≤2）

### 单集四段式（抽检3-5集）
- [ ] 开头有钩子（≤30秒内）
- [ ] 结尾有悬念钩子
- [ ] 无纯铺垫集（情绪峰值≥6）

## 人物逻辑一致性

- [ ] 主角性格全程一致
- [ ] 人物决策有动机支撑
- [ ] 人物成长有事件触发
- [ ] 反派有可理解的动机
