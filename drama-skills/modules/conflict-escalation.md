# 模块：冲突升级

> 挂载角色：`drama.story-bible`（全剧冲突链）、`drama.episode-designer`（单集对峙设计）

## 四类冲突

| 类型 | 来源 | 短剧常用形态 |
|------|------|------------|
| 外部 | 环境/社会 | 破产、裁员、天灾、规则压迫 |
| 人际 | 关系/利益 | 婆媳、职场、情敌、家族争产 |
| 内心 | Ghost/Lie | 自我怀疑、道德两难、身份认同 |
| 命运 | 结构性对立 | 阶层壁垒、时代洪流、宿命诅咒 |

全剧必须至少覆盖 3 类；主线冲突须是「结构性对立」（不能一次和解就消失）。

## 升级协议（每次升级必须换维度，禁止同烈度重复拉扯）

```
范围升级：个人矛盾 → 家庭 → 公司 → 行业/社会
烈度升级：口角 → 利益损失 → 名誉/关系破裂 → 生存威胁
信息升级：新证据/新身份曝光改变博弈格局
后果升级：可挽回 → 需代价挽回 → 不可挽回
```

## 对峙场景五要素

设计任何对峙场景（吵架、谈判、摊牌）必须写明：

1. 势力对比（谁占上风，凭什么）
2. 表面诉求（台词层在争什么）
3. 真实意图（潜台词层要什么）
4. 权力拉锯（上风至少易手 1 次）
5. 场景转折（结束时价值状态与开始不同——McKee 检验）

## 自检清单

- [ ] 全剧冲突链每次升级都改变了冲突质量（换维度）
- [ ] 主线冲突不能被一次对话解决
- [ ] 每个对峙场景五要素齐全
- [ ] 反派的反击有合理逻辑，禁止降智式失败（LR-004）
