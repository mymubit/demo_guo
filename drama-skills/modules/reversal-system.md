# 模块：反转体系

> 挂载角色：`drama.story-bible`（全剧反转布局）、`drama.episode-designer`（单集反转）

## 五类反转（按冲击力排序）

| 类型 | 定义 | 铺垫要求 |
|------|------|---------|
| 身份 | 真实身份与表面身份反差揭露 | S 级需 3+ 集误导铺垫（LR-005） |
| 动机 | 某角色行为的真实目的曝光 | 前序至少 2 处「无关细节」线索 |
| 关系 | 角色间真实关系颠覆认知 | 需要既有关系的充分建立 |
| 局势 | 强弱格局瞬间倒转 | 翻盘筹码必须提前埋设 |
| 真相 | 核心事件的真相与呈现相反 | 全剧级悬念，最后 25% 揭露 |

## 逆向设计法

先定「揭露场景」再倒推铺垫：

1. 写出揭露时刻的理想观众反应（震惊但服气：「原来如此，早有暗示」）
2. 倒推需要哪些线索，把线索伪装成「无关细节」埋进前序集
3. 埋点与揭露间隔：B 级 1-3 集 / A 级 3-5 集 / S 级 5+ 集
4. 每条反转线索写入伏笔总表（埋点集 → 计划回扣集）

## 布局密度（全剧层）

- 每 5 集 ≥1 次 A 级反转
- S 级反转揭露窗口：全剧 55-75% 处（危机前夕）
- 反转密度参考题材 `rule_params.reversal_density`（四轴合成，0.3-0.5 区间常见）
- 揭示场景必须有仪式感（专属场景/道具/视觉记忆点），禁止对白顺带带过

## 自检清单

- [ ] 每个反转能回答「哪几集埋了什么线索」
- [ ] 无「无铺垫硬反转」；线索以无关细节形式呈现
- [ ] S 级反转在 55-75% 窗口内且有仪式感场景
- [ ] 反转后新格局能推动后续剧情，不是为转而转
