# 模块：世界规则设计

## 目标
建立能够驱动人物选择、冲突和代价的轻量世界规则，而不是编写背景百科。

## 输入
- 核心概念、题材矩阵和人物系统
- 目标平台与篇幅

## 引用规则
- `t1.global.world_rules.actionable`
- `t1.global.world_rules.power-structure`
- `t1.global.world_rules.information-release`
- `t1.global.world_rules.consistency`

## 输出
- `story_bible.world_rules.setting_summary`
- `story_bible.world_rules.root_rules`
- `story_bible.world_rules.power_structure`

## 执行步骤
1. 提取会影响目标、资源、选择或代价的规则。
2. 为每条规则写触发条件、适用对象、违反代价和可见表现。
3. 描述权力与稀缺资源如何持续制造主线冲突。
4. 规划规则的首次展示与后续验证位置。

## 失败条件
- 设定不影响任何人物行动。
- 通过旁白或解释性台词集中讲规则。

## 自检清单
- [ ] 每条规则至少驱动一次具体选择
- [ ] 例外有来源和代价
- [ ] 后续分集无需临时增加破局规则
