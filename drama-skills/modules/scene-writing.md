# 模块：场景写作

## 目标
把分集卡转化为可拍摄、持续冲突并发生价值变化的场景。

## 输入
- 本集分集卡
- `story_bible`
- 上一集正文与连续性检查点

## 引用规则
- `t1.global.philosophy.cross-section`
- `t1.global.philosophy.mckee-value-shift`
- `t1.global.writing_requirements.scene-unit`
- `t1.global.writing_prohibitions.unfilmable`
- `foundation/constraints/script-format.yaml`

## 输出
- 场景头
- 动作、台词与场景价值变化
- 本集正文

## 执行步骤
1. 从当前冲突最晚可进入的位置切入场景。
2. 明确角色目标、阻碍、风险和表面/真实意图。
3. 通过行动与潜台词推动上风易手。
4. 在价值状态改变后尽早离场，并承接下一场。

## 失败条件
- 场景只有信息说明，没有目标和阻碍。
- 使用心理描写或括号解释不可拍内容。

## 自检清单
- [ ] 每场 Goal×Conflict 明确
- [ ] 开场与结尾价值状态不同
- [ ] 所有信息都能由镜头或声音呈现
