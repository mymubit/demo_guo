# 抖音爆款公式库（Douyin Formula Library）

> **参考公式库**；与本文档及 `modules/formula-analysis.md` 同步维护
> 数据来源：抖音短剧TOP50分析（2026年6月，数据平台：duanjugongcheng.com）
>
> **核心洞察**：2026年抖音短剧正在从"情绪爽感→人格共鸣"转型。观众不只要打脸时的肾上腺素，更要"这个角色像我"的代入感。

---

## 标签三级体系（火箭模型）

| 级别 | 作用 | 最低频率 | 代表标签 |
|------|------|---------|---------|
| **通用型** | 短剧底层操作系统，爆款通常含其中2个 | ≥15部/50 | #总裁 #逆袭 #打脸虐渣 #大女主 #都市爱情 |
| **场景型** | 打开方式，定向触达特定兴趣圈层 | 5-14部/50 | #豪门恩怨 #婚姻危机 #职场 #古风 |
| **情绪型** | 做差异化，主打特定情绪体验 | <5部/50 | #心动 #反转 #治愈 #爽到飞起 |

**核心规律**：每个爆款组合为4个标签的精密配比；标签之间的关系比标签本身更重要。

## 8大爆款公式

### 公式1：隐藏身份×打脸反转

```
标签：#隐藏身份 + #打脸 + #逆袭 + #大女主（或总裁）

核心机制：
  主角伪装弱者→被人轻视欺压→真实身份揭露→碾压反转

关键设计：
  隐藏身份暗示集数与揭露窗口读取 foundation/constraints/narrative-metrics.yaml#s_reversal_foreshadow
  （揭露窗口 SSOT 为 commercial-formulas.yaml#s_reversal_window，禁止在本文另行取值）
  揭露后：不能立刻解决所有问题，要有新的挑战

适用题材：豪门霸总/都市逆袭/古装权谋
```

### 公式2：双强博弈×势均力敌

```
标签：#双强 + #博弈 + #都市爱情 + #商战

核心机制：
  两个同样强大的角色正面交锋→互相试探→在博弈中产生情感

关键设计：
  两人实力要真正对等（不能一方明显弱于另一方）
  博弈过程要有"高手过招"的智识感
  情感线穿插在博弈间隙

适用题材：商战/古装权谋/职场
2026趋势：取代传统"霸总追妻"，已是都市爱情主流
```

### 公式3：命运反转×人格觉醒

```
标签：#人格觉醒 + #女性成长 + #逆袭 + #打脸

核心机制：
  主角从压抑状态→触发点→彻底觉醒→用新姿态面对旧压迫

关键设计：
  觉醒前的压抑要够真实（观众要感到愤怒/心疼）
  觉醒触发点要有力（不能是随机事件）
  觉醒后主角的变化要显著

2026年最强势赛道：女性成长，上限极高
```

### 公式4：甜虐交替×日常流

```
标签：#甜宠 + #日常 + #治愈 + #心动

核心机制：
  在真实感极强的日常中，穿插高密度的甜点时刻
  
关键设计：
  甜点密度：平均每1.5集1个甜点
  甜点类型多样：心动/错位理解/偶然接触/守护
  虐心设置：每5-7集来一次小危机，然后用更大的甜点解决
  
注意：日常流不需要大冲突，但需要细节真实感
```

### 公式5：时代命题×共情共鸣

```
标签：#女性成长 + #真实 + #共鸣 + #职场

核心机制：
  精准踩中当下热点社会情绪→角色经历映射观众真实处境→情感共鸣

2026热门命题：
  - 反PUA/不恋爱脑
  - 身份焦虑/阶层流动
  - 职场天花板
  - 原生家庭议题

关键设计：主角的处境要让目标观众觉得"这就是我"
```

### 公式6：古风美学×情感张力

```
标签：#古风 + #虐恋 + #家国情仇 + #大女主

2026增长最快赛道（+52%）

核心机制：
  精致的古风视觉包装下，放现代化的情感逻辑

关键设计：
  视觉：服饰/场景要有辨识度，不能廉价
  情感：冲突逻辑要现代化（家国>爱情/身份悬殊/命运对抗）
  卖点：女性角色必须有足够的主体性
```

### 公式7：悬疑标签×情绪体验

```
标签：#悬疑 + #反转 + #时间线 + #双重身份

核心机制：
  悬念不是目的，悬念是制造"想知道答案"情绪的工具

关键设计：
  每集至少有1个新悬念（旧悬念解决前开新悬念）
  反转要有逻辑铺垫（事后回看觉得"原来如此"）
  不能只有智力游戏，要有情感依附点
```

### 公式8：反套路×类型颠覆

```
标签：#反套路 + [原题材标签]

核心机制：
  用熟悉的类型外壳包裹意料之外的内核

2026案例：
  甜宠剧女主不恋爱脑，男主来追女主
  霸总剧里女主才是隐藏大佬
  家庭剧里丈夫比妻子更想离婚
  
关键设计：
  反套路要在第1集就明确展示
  反套路元素要贯穿全剧，不是一时噱头
```
