# 原创性保护规则（Originality Protection Rules）

> **参考规则库**；新条目请写入 `foundation/rules/`
> 含2026广电新规/AI漫剧肖像权/出海版权保护
>
> **使用方式**：drama.story-bible（改编模式提取补全时执行原创性自检）、drama.compliance-guard（最终合规检测）。

---

## 保护分类体系（6类）

| 分类 | 受保护内容 | 检测方法 | 处理策略 |
|------|-----------|---------|---------|
| **角色名保护** | 受版权/商标保护的角色名 | IP数据库字符串匹配+语义相似度 | 随机生成原创名（保留性别/年龄感） |
| **标题保护** | 作品标题和标语 | 语义相似度+关键词哈希（阈值0.72） | 三要素重生成：身份+冲突+悬念 |
| **情节保护** | 逐集结构/关键桥段 | 结构哈希+反转点指纹比对 | 保留节奏规律，替换具体内容 |
| **台词保护** | 金句/标志性对话 | 短语哈希+相似度检测（阈值0.80） | 保留情绪和意图，改写表达方式 |
| **AI漫剧保护** | 角色形象/声纹 | 形象描述对比 | 不使用与现有IP相似的视觉描述 |
| **出海版权** | 出海目标市场版权 | 目标国家IP数据库检索 | 本地化角色名（符合目标文化） |

## 受保护角色名示例及替换策略

```
受保护示例：范闲/魏无羡/梅长苏/甄嬛/许三多
           Sherlock Holmes/Harry Potter

替换策略：
  中文：随机组合姓氏+诗意或符合人设的名字
  示例：梅长苏 → [沈知远/秦子瞻/苏玄策]

  外文：使用中文原创名，避免谐音或明显致敬

禁止：
  - 直接使用受保护角色名
  - 谐音字（如"王菲"→"汪飞"）
  - 同字不同意（如"长苏"→"长苏辞"）
```

## 标题原创性三要素替换法

```
标题生成公式：主角身份 + 核心冲突 + 反转悬念

受保护标题识别：相似度 > 0.72 → 触发重生成

示例：
  参考剧：《错嫁总裁》
  原创生成：《（医生/教师/...）的（复仇/秘密/...）》
  避免：《错嫁xxx》《x嫁总裁》
```

## 情节原创度检测

```
逐集结构指纹对比：
  提取：各集反转点位置（第X集第Y分钟）
  对比：与参考剧本指纹的差异度
  目标：> 80%（即结构位置不超过20%相似）

桥段去重：
  典型受保护桥段：
  - "公司门口被前任现任撞见"
  - "医院走廊里误会病情"
  - "在婚礼现场当众揭发"
  
  处理：识别后改变场景/时机/人物组合，保留戏剧功能
```

---

## 台词原创度（相似度阈值 0.80）

```
检测：字符串相似度 > 0.80 的台词片段 → 触发重写

典型需要重写的情况：
  - 与参考剧本金句高度相似（如只改1-2个字）
  - 整段对话结构相同（即使用词不同）
  - 标志性口头禅（如某IP专属的说话方式）
```

## 2026 AI内容新规（出海必看）

```
《人工智能生成合成内容标识办法》关键要求：
  1. AI生成内容必须有明确标识
  2. 虚拟形象必须获得原型授权（肖像权/声纹权）
  3. 出海内容需符合目标国AI内容法规

实操要求：
  - 平台发布时：勾选"AI辅助创作"标识
  - AI漫剧：角色设计不得与知名IP形象高度相似
  - 配音：TTS合成声音不得模仿现实中存在的特定人物声音
```
