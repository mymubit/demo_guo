# 跨项目经验规则（Learned Rules）

> 来源：从 StoryForge 仓库、行业经验和本系统实际生成案例中提炼。
> 当同类修改出现 2 次以上时，沉淀为此处的跨项目规则。

## 规则格式
每条规则包含：规则 ID、赛道适用范围、规则内容、原因。

---

## 一、StoryForge 来源规则（已验证）

### LR-001：复仇类第一集前30秒必须展示主角被欺压
- **适用范围**：复仇/逆袭赛道
- **规则**：第一集第一场戏，必须在开场 30 秒内展示主角处于劣势/被欺压的具体场景
- **原因**：观众需要快速建立对主角的同情 + 对反派的愤怒，这是后续所有爽感的心理基础
- **违反示例**：开场展示主角逛街、上班、正常生活

### LR-002：甜宠类对白不超过3句连续内心独白
- **适用范围**：甜宠/治愈赛道
- **规则**：任何角色不能有超过 3 句连续的内心独白（心理描写）
- **原因**：过多独白破坏甜宠节奏，观众想看互动、眼神交流、肢体语言，不是内心戏

### LR-003：付费墙前最后一集的结尾钩子必须是全剧最强
- **适用范围**：所有赛道
- **规则**：付费转换点前的最后一集，结尾 cliffhanger 强度必须是全剧 S 级
- **原因**：这是决定用户是否付费的关键时刻，钩子不够强 = 直接流失付费用户

### LR-004：反派不能靠降智失败
- **适用范围**：所有赛道
- **规则**：反派的失败必须有合理逻辑，不能因为"突然变蠢"而输给主角
- **原因**：反派太蠢 → 主角胜利含金量低 → 观众爽感显著下降
- **反例**：反派面对明显证据视而不见；反派放弃已到手的优势

### LR-005：身份揭示场景必须有足够铺垫和仪式感
- **适用范围**：有身份反转的赛道（隐藏大佬/重生觉醒/跨世界者）
- **规则**：S 级身份反转必须有 3 集以上的误导铺垫，揭示场景本身要有仪式感（专门的场景、充足的时间、情绪到位）
- **原因**：草率揭示 = 浪费全剧最大爽点

## 二、G-Eval 评分行业规则

### LR-006：每集推进型节拍占比必须 ≥ 60%
- **适用范围**：所有赛道
- **规则**：每集场景中，"推进型"（推动事件/关系/信息发生变化）的节拍数占比 ≥ 60%
- **原因**：低于 60% = 叙事效率不足，观众感觉"什么都没发生"
- **检测方法**：逐场景标记"推进型/静态型/冗余型"，计算比例

### LR-007：付费点位置 = 全剧最大张力处
- **适用范围**：所有赛道
- **规则**：第一个付费卡点应设在第 3-5 集（建立情感投入后），付费后 1 集内必须立即兑现
- **原因**：付费墙在最大张力处 → 用户愿意付费；付费后无立即兑现 → 退款/差评

## 三、上下文加载规则（防止 Token 爆炸）

### LR-008：逐集生成时只加载上一集+快照+伏笔列表
- **适用范围**：10集以上的剧本生成
- **规则**：生成第 N 集时，不要加载前 N-1 集全文，只加载：
  1. 第 N-1 集全文（保证连贯性）
  2. 角色状态快照（当前状态，不是历史）
  3. 伏笔清单（已埋/未回扣/已回扣）
  4. 大纲第 N 集条目（方向指引）
- **原因**：加载全部历史 → Token 爆炸（100集≈100万token），质量下降，成本飙升

---

## 四、双轨节奏规则（山音）

### LR-009：不允许连续3集松+轻组合（喘息集过多）
- **适用范围**：30集以上剧本
- **规则**：松+轻的喘息集每10集最多出现1次，不允许连续出现
- **原因**：连续喘息 = 中段疲软，观众弃剧率显著上升

### LR-010：危机爆发集必须是紧+重组合
- **适用范围**：所有赛道
- **规则**：大反转/身份揭示/决裂场景所在集，必须是情节[紧] × 情感[重]组合
- **原因**：危机集如果情感节奏偏轻，情绪爆发力不足，错失高光时刻

---

## 沉淀流程

1. 用户对生成结果不满意，进行了修改
2. 修改内容和原因记录在项目级 `lessons.md`
3. 同类修改在不同项目出现 ≥ 2 次 → 提示用户确认是否沉淀
4. 用户确认后，写入此文件
5. 后续所有项目的生成和评估自动参考此文件
