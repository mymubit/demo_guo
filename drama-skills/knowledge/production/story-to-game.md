# Story-to-Game：剧本→互动文游转化工具

> **来源**：https://github.com/Shanyin-ai/Story-to-game（292 stars · MIT）
> **作者**：@山音 · 摄取时间：2026-06-22
>
> **核心价值**：可以将创作完成的短剧剧本转化为可玩的互动分支叙事游戏（JSON格式），并配套HTML启动器直接在浏览器运行。这为短剧衍生品/用户互动/营销物料开辟了新方向。

---

## 什么是 Story-to-Game

将小说/剧本/故事大纲转化为**分支叙事游戏**（interactive branching narrative game）。

```
输入：短剧剧本/大纲
  ↓ Story-to-Game AI 技能（九步工作流）
输出：JSON格式的互动游戏脚本
  ↓ HTML启动器
玩家：在浏览器中游玩分支剧情
```

---

## 核心能力

| 能力 | 说明 |
|------|------|
| **多体量适配** | 短篇/中篇/长篇/剧本/大纲，自动规划节点数和游玩时长 |
| **风格保真** | 提取原作叙述温度/对白规则/节奏型，防止风格漂移 |
| **分支设计** | 态度/路径/命运三类分支按比例分配，每个分支内容饱满 |
| **状态系统** | 戏剧化主状态值 + 多类型结局矩阵 |
| **自动验证** | 13项自动校验（节点可达性/引用完整性/结局完整性等）|

---

## 分支类型

| 类型 | 定义 | 占比建议 |
|------|------|---------|
| **态度分支** | 玩家选择角色的态度/情绪（强硬vs温和） | 40% |
| **路径分支** | 玩家选择行动方向（A路线vs B路线） | 35% |
| **命运分支** | 关键决策点，影响结局走向 | 25% |

## 对 drama-skills 的扩展意义

### 已落地：drama.delivery-tool 的 story-to-game 模块

该能力已作为 `modules/story-to-game.md` 挂载在宣发交付工具下，将完成的短剧剧本转化为互动游戏版本：

```
输入：完整短剧剧本（03_完整剧本/）
  ↓
Step1：摄入分析（提取关键决策节点）
Step2：风格指纹（保留原作语感）
Step3：分支设计（将线性剧情改写为三类分支）
Step4：状态系统（设计主状态值和结局矩阵）
Step5-9：分段写作+验证输出

输出：
  - 可玩的 JSON 游戏文件
  - 配套的营销/互动体验版本
```

### 短剧 + 互动游戏的商业价值

1. **营销物料**：发布剧本前，发布互动游戏版预热
2. **用户粘性**：让观众在追剧的同时参与故事选择
3. **衍生品**：剧集完结后，推出"另一种结局"互动游戏版
4. **创作验证**：通过玩家选择数据验证哪些分支最受欢迎，反向优化下一部剧
