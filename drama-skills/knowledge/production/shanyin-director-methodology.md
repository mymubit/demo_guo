## 一、九列标准分镜表格式

基于用户真实导演作品（551个有效镜头）统计分析。

| 列 | 说明 | 填写规范 |
|----|------|---------|
| **镜号** | 连续编号从1开始 | 多行对白只在第一行填写 |
| **时长** | `MM:SS-MM:SS` | 最后一镜写 `MM:SS-结束` |
| **摄影角度** | 俯仰维度 | 平视/俯拍/仰拍/微俯拍/极高俯拍 |
| **景别** | 人物呈现比例 | 大全景/全景/中景/中近景/近景/特写 |
| **画面内容** | 可见的视觉内容 | 角色动作/环境/视觉效果 |
| **场景** | 拍摄空间 | 城市街道/室内客厅/抽象空间 |
| **声音** | 所有声音元素 | 对白/旁白/音效/配乐 |
| **备注** | 技术说明 | 特效/字幕/镜头运动 |
| **叙事目的** | 该镜头的叙事功能和视听意图 | 见叙事目的写法规范 |

## 二、镜头时长统计基准（来自551个真实镜头）

**整体基准（短片）**：平均4.2秒/镜，中位数3秒，76%的镜头在1-5秒。

### 按叙事动作类型

| 叙事目的类型 | 短片基准 | 说明 |
|-------------|---------|------|
| 推进/升级 | 2.5-3.5秒 | 最快 |
| 交代/建立 | 4-5秒 | 需要让观众看清信息 |
| 展现/呈现 | 4-5秒 | 标准展示时长 |
| 情绪/氛围 | 4-5秒 | 需要给氛围"呼吸" |
| 呼应/闭环 | 4-5秒 | 让观众认出呼应关系 |
| 转折/翻转 | 5-7秒 | 翻转的重量需要时间落地 |
| 升华/主旨 | 6-10秒 | 最慢，终极意象需停留 |

### 按内容表达量

| 内容量 | 基准 | 典型 |
|--------|------|------|
| 单一信息 | 2-3秒 | 物件特写/简单动作 |
| 双重信息 | 4-5秒 | 动作+环境/台词+反应 |
| 多层信息 | 6-8秒 | 复杂场面/多人互动 |
| 综合段落 | 10-15秒 | 长镜头/情绪留白 |

### 台词时长估算方法

**不用字数估算，而是"在脑中演一遍"**：
用这个角色在这个情境下会用的语速、停顿和呼吸方式去读，读完的时间就是台词需要的最少时间。台词时间+反应时间（对方停顿/表情变化）= 镜头最少时长。

## 三、叙事目的分析法（结构+导演双层）

每个场景/镜头的叙事目的包含两层：

**结构层（叙事功能）**：
- 交代信息（人物/空间/时间/规则）
- 建立/强化角色特征
- 推进情节（制造/升级/翻转冲突）
- 埋设/回扣伏笔
- 呈现主题论点
- 首尾呼应/结构对称
- 情绪转场/节奏调节（呼吸点）

**导演执行层（视听意图）**：
- 制造不安感/压迫感/窒息感
- 控制观众视线/引导注意力
- 制造时间感（压缩/拉伸/停滞）
- 用视觉隐喻传达不可言说的内容
- 建立或打破观众的预期

**好的叙事目的写法示例**（来自真实作品）：
```
"用荧光灯的闪烁制造不安，走廊纵深构图暗示秘密的深度，
A发现秘密时不用特写而是保持中景——让观众自己在肢体语言中读出震惊。"

"形成视觉与叙事上的双重闭环，开启属于主角的新一轮情感循环。"

"用一个毫无实际意义的模拟动作收尾，将系统的荒谬与虚无感推至极点。"
```

**写法要点**：
- 一句话同时覆盖"做什么"和"为什么这么做"
- 具体到视听手段（不是"展现关系变化"，是"用背对背构图展现疏离"）
- 当有隐喻/母题时，点明叙事功能
- 语气客观分析，不煽情

## 四、动作-反应镜头设计（10种变体）

镜头设计的基本单元 = **动作（行为）镜头 + 反应（结果）镜头**

| 变体 | 结构 | 效果 | 适用场景 |
|------|------|------|---------|
| **标准型** | 动作→反应 | 清晰因果 | 常规叙事 |
| **反应前置** | 反应→动作 | 制造悬念（先看结果再看原因） | 需要强好奇心的场景 |
| **动作并置** | A→B→C→反应 | 累积压力，反应被放大 | 多线事件汇聚 |
| **反应省略** | 动作→（无反应） | 留白，想象中的反应更强 | 情感需要留白的时刻 |
| **动作隐藏** | 声音动作→视觉反应 | 声画分离，想象力参与 | 恐怖/震撼场景 |
| **反应延迟** | 动作→日常→日常→反应 | 真实感（人需要时间消化） | 重大冲击后的反应 |
| **同步型** | 动作与反应同画面（长镜头） | 观众自选，信息密度高 | 需要真实感的场景 |
| **反应链** | 动作→反应A→反应B→反应C | 展示事件的辐射范围 | 公告/重大消息场景 |
| **重复渐变** | 同一动作微变+不同反应 | 时间推移+情绪累积 | 展示角色状态变化 |
| **省略动作** | 只看反应，动作从不出现 | 观众拼凑真相 | 悬疑场景 |

## 五、对九列分镜模块（drama.revision-master · storyboard-9col）的直接升级

```markdown

```

## 六、场景节奏自检（来自导演方法论）

- [ ] 是否每场戏都有叙事目的？（无目的考虑删除）
- [ ] 叙事目的是否均匀分布？（信息交代不要全集中在前段）
- [ ] 伏笔/回扣是否成对出现？
- [ ] 主题通过视听动作传达，而非台词说出？
- [ ] 连续3场高强度后是否有呼吸点？
