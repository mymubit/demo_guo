# 山音导演分镜 · 执行清单（注入用）

> 长文原件：`knowledge/production/shanyin-director-methodology.md`、
> `knowledge/production/shanyin-director-styles.md`（仅人读，不注入）。

## 九列分镜必填
镜号 / 时长 / 摄影角度 / 景别 / 画面内容 / 场景 / 声音 / 备注 / 叙事目的

## 叙事目的
- 每镜写清：推进情节 / 人物关系 / 情绪 / 信息 / 节奏 中的哪一类
- 禁止空「好看」「氛围」而无叙事功能

## 镜头设计
- 优先动作-反应配对；景别跳切需有动机
- 对白戏：反应镜不少于对白镜的 1/3

## 风格
- 选定 1 个主导风格模板后全片/全交付包保持一致，禁止混搭堆砌
