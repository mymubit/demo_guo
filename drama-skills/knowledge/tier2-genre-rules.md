# Tier2 品类规范（Genre-Specific Rules）

> **来源**：整合 dramaskilltrae `config/` 目录的规则库 JSON 文件
> 
> **使用方式**：创作前根据题材选择对应区块，作为 Tier1 的补充约束。
> **适用角色**：drama-world-architect / drama-character-designer / drama-plot-architect / drama-dialogue-expert

---

## 一、情绪锚点库（Tier2-emotion-anchor）

按题材定位核心情绪共鸣点，确保剧情触发目标受众的真实情绪。

### 现代都市

| 细分 | 核心情绪锚点 |
|------|------------|
| **逆袭/职场** | 普通人面对不公的反抗爽感；打工人对PUA的反抗与觉醒；小镇青年在大城市的立足焦虑；裁员潮下普通人的生存困境 |
| **甜宠/情感** | 母胎solo第一次恋爱的笨拙心动；成年人恋爱的拉扯与权衡；双向暗恋的小心翼翼与试探；强势群体在爱情里的软肋暴露 |
| **家庭/生活** | 原生家庭带来的性格阴影与和解；全职妈妈的自我价值困境；婆媳关系里的进退两难；当代年轻人的恐婚恐育焦虑 |

### 古装/年代

| 细分 | 核心情绪锚点 |
|------|------------|
| **复仇/权谋** | 底层小人物被践踏后的绝地反击；失去一切后的隐忍与复仇执念；女性在男权社会的挣扎与自我实现；世家子弟在朝代更迭里的命运沉浮 |
| **甜宠/言情** | 深宫高墙里的真心难寻；穿越者在古代的生存智慧与孤独；先婚后爱的试探与动心；身份悬殊的禁忌之恋的拉扯 |

### 其他题材

| 题材 | 核心情绪锚点 |
|------|------------|
| **悬疑/犯罪** | 普通人卷入案件后的恐慌与求生；受害者家属寻求真相的执念；执法者面对正义与规则的两难；长期被忽视的弱势群体的复仇 |
| **喜剧/治愈** | 社恐人士面对社交的窘迫与温暖；倒霉蛋接连遇到糟心事的自嘲；失意者在小地方找到人生意义 |
| **商战** | 创业者面对背叛后的重建；职场新人vs老手的代际博弈；商人在义与利之间的取舍 |

## 二、台词声音差异化规则（Tier2-dialogue-voice）

按角色阶层/职业/情绪状态给出台词写作规范，确保每个角色开口就有识别度。

### 阶层/背景维度

| 阶层 | 语言特征 | 典型表达方式 |
|------|---------|------------|
| **底层/体力劳动者** | 直接、口语、无修饰 | 大白话、方言口音、偶有脏话、声音大 |
| **中产/知识分子** | 用词讲究、逻辑清晰 | 专业术语、留有余地、少脏话、喜欢讲道理 |
| **上层/权贵** | 简短、惜字如金 | 反问/暗示、语气平淡、有压迫感、不直说 |

### 职业维度

| 职业 | 语言特征 |
|------|---------|
| **学生** | 网络热词、夸张感叹、句子短、跳跃性强 |
| **职场人** | "对齐""闭环""抓手""赋能"；汇报先说结论；PPT逻辑说话 |
| **生意人** | 客套打太极；什么都答应不明确承诺；三句不离商机 |
| **公职人员** | 官方严谨；永远是"研究研究"；滴水不漏 |

### 情绪维度（外化到台词节奏）

| 情绪状态 | 台词节奏特征 |
|---------|------------|
| **极度愤怒** | 句子极短、一字一顿、重复相同的话、语无伦次 |
| **极度悲伤** | 断断续续、有停顿、声音很小、句子不完整 |
| **极度开心** | 语速快、语调高、重复用词（"太开心了太开心了"）、逻辑跳跃 |
| **紧张/撒谎** | 结巴、有停顿；重复说"真的""我没有骗你"；主动解释多余细节 |
| **强装镇定** | 语速刻意均匀；用词太过完整和逻辑；停顿在不该停的地方 |

## 三、角色行为逻辑库（Tier2-character-logic）

按年龄段定义角色的核心命题、决策模式和行为特征，确保人物反应符合人性。

| 年龄段 | 核心命题 | 决策模式 | 行为特征 |
|-------|---------|---------|---------|
| **20岁（青年）** | 我是谁，要成为什么样的人 | 优先喜不喜欢，其次对错；冲动，不考虑长远 | 社交活跃；不服管、挑战权威；感情纯粹全力付出 |
| **30岁（而立）** | 我现在的生活是我想要的吗 | 现实与理想的权衡；开始看长远；怕犯大错 | 开始选择性社交；竞争感强；消费理性 |
| **40岁（中年）** | 我还有机会改变吗 | 以稳定为第一优先级；谨慎保守 | 上有老下有小的疲态；怀念年轻时的选择 |
| **50岁+（知天命）** | 我这辈子过得值吗 | 看淡得失；关注传承和留下什么 | 喜欢说教；对年轻人有控制欲；害怕孤独 |

## 四、悬念节奏规则（Tier2-suspense-rhythm）

三层悬念结构，确保全程维持追看动力。

### 信息差三类型

| 类型 | 运用方式 | 效果 |
|------|---------|------|
| **观众知道·角色不知道** | 观众知道凶手/卧底，主角一步步接近 | 代入感+焦虑感 |
| **角色知道·观众不知道** | 角色有秘密，观众好奇 | 持续追看动力 |
| **双重知情博弈** | 两人互相知道对方的底牌，各自演戏 | 高级张力 |

### 信息释放节奏规则

```
基础信息（身份/世界观）→ 按需分批，不要一开始全说出来
核心信息（真相/凶手）→ 延迟到最后，不到时刻不公布
情感信息（关系细节/过去）→ 自然渗透，慢慢积累情感

滚动悬念设计：每解开一个谜题，同时产生新谜题
                              禁止：悬念断层
```

### 时间线错位使用规则

- 把结果放在原因之前，制造认知缺口
- 切换时间点要发生在情绪高点
- 不同时间线之间保持持续的情感呼应
- 禁止：为了炫技而错位，要服务于主题

## 五、市场适配规则（Tier2-market-adaptation）

### 钩子电梯测试（合格钩子三要素）

```
1. 鲜明的人物处境：一句话说清楚主角是什么人，遇到了什么事
2. 清晰的核心冲突：主要矛盾是什么，对手/障碍是什么
3. 未解的问题：观众听完想知道结果，有追看欲望

测试方法：把钩子讲给完全不知道这个故事的陌生人听
         如果对方听完问"然后呢？"，就是合格的钩子
```

### 类型差异化路径

| 路径 | 做法 | 效果 |
|------|------|------|
| **反类型** | 用熟悉类型外壳包裹意料之外内核（如甜宠剧女主不恋爱脑） | 新鲜感 |
| **类型杂交** | 融合两种不相关类型（甜宠+悬疑/喜剧+权谋） | 差异化 |
| **视角颠覆** | 从反派/动物/配角视角重述熟悉故事 | 记忆点 |

### 2026年主流用户情绪匹配

| 受众 | 当前主导情绪 | 内容对应 |
|------|------------|---------|
| **年轻人18-25** | 反内卷、躺平、身份焦虑、渴望真诚情感 | 反PUA/反说教/真实感 |
| **中坚25-35** | 职场天花板、家庭与个人平衡、对稳定的渴望 | 逆袭/和解/情感陪伴 |
| **下沉市场** | 家庭情感、被社会主流忽视、强烈的公平感需求 | 家庭剧/乡村逆袭/温情 |
