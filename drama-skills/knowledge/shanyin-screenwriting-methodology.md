## 一、横截面理论（核心地基）

> "电影是现实生活的横截面。"

```
错误思维：从角色出生讲到角色死亡（流水账）
正确思维：从完整人生中切出一段有张力的横截面

四个含义：
1. 故事开始之前，世界已经运行了很久
   → 角色带着前史走进第一场戏
2. 故事从中间开始
   → 好的开场 = 从最有张力的截面切入
   → 观众通过角色行为反推前因（比顺叙更有吸引力）
3. 开场即态度
   → 第一场戏定义全片的气质（不是主题）
4. 编剧的工作：先建造完整世界，再切一刀
   → 工作流：先建造 → 再裁切
```

**短剧应用**：第1集第一场戏，不要从头讲起——直接切入最大张力的横截面。

## 二、戏剧动作：故事最小单位

```
戏剧动作 = 目标(Goal) + 阻碍(Conflict)

不是"一个人想喝水"
而是"沙漠中一个脱水的人找水"
```

检验：目标有急切性？目标与阻碍有强烈冲突关系？

## 三、人物设计进阶框架

### Want vs Need

```
外在需求(Want)：角色主动追求的（角色自己意识到的）
内在欲望(Need)：角色灵魂缺口（自己未曾意识到的）
张力 = 弧光的发动机
```

### Ghost / Lie / Flaw（长片/剧集深度层，补充"欲望-恐惧-缺陷三角"）

```
Ghost（前史创伤）：过去发生的一件事，至今影响行为
  → 解释：为什么有这个Want，为什么看不到自己的Need

Lie（角色相信的谎言）：因Ghost形成的错误世界观
  → "我不能信任任何人" / "努力就一定成功"

Flaw（性格缺陷）：由Lie引发的、导致悲剧的行为模式
  → 弧光 = 角色从Lie中醒来，接受了真相
```

**矛盾性**：好角色至少有一层矛盾（外在自信 vs 内在自卑）

## 四、写作红线（全格式通用）

**绝对不要：**
- 写心理描写（"他意识到"、"内心涌起"）
- 括号暗示（"（其实是在掩饰紧张）"）
- 角色用台词解释设定或主题
- 说教片段、强行催泪
- AI腔台词
- **写任何无法被摄影机拍到的内容**

**潜台词示例**：
```
直白（错）："我很害怕失去你。"
潜台词（对）："你走的时候把那件外套带上。……外面冷。"
```

## 五、双轨节奏系统（对现有体系的重要补充）

现有 drama-skills 只有单轨情绪曲线。山音体系提供双轨视角：

```
外部情节节奏（事件密度）：松 / 中 / 紧
内在情感节奏（情感投入）：轻 / 中 / 重
```

**四种错位组合**（这是高级叙事手法）：

| 情节 | 情感 | 效果 | 典型场景 |
|------|------|------|---------|
| 松 | 重 | 越平静越沉重 | 分离前夕的平静相处 |
| 紧 | 轻 | 紧张被轻盈包裹 | 轻松配乐的激烈追逐 |
| 紧 | 重 | 全片顶点（高潮） | 最终对决 |
| 松 | 轻 | 纯粹呼吸 | 高潮前后的休息场景 |

**upgrade建议**：drama-rhythm-designer 在标注 EV/ET/TP 时，同步标注"情节节奏+情感节奏"双轨，主动设计"松+重"这类高级错位。

## 六、McKee价值转变检验

> "场景结束时的核心价值是否与开始时不同？若相同，考虑删掉这场戏。"

**应用**：drama-script-reviewer 加入检验项：
- [ ] 每场戏开头和结尾的"价值状态"是否发生了转变？

## 七、记忆检查点系统（长内容防前后矛盾）

**触发时机**：每完成一集（剧集）/ 每个Sequence（长片）

**检查点模板**：
```
📌 记忆检查点 #N | 第X集完成
【角色状态】[角色名]：物理/情感/已知/想要
【活跃线索】- [线索]：状态
【伏笔状态】已埋未回扣：[内容] → 计划[位置]回扣
【节奏状态】上一段：情节[松/中/紧]+情感[轻/中/重]
          → 下一段建议：[方向]
```

**应用**：drama-script-writer 完成每集后自动触发，防止多集剧本的伏笔/人物状态前后矛盾。

## 八、开场钩子分类（按格式）

| 格式 | 策略 | 核心功能 |
|------|------|---------|
| 商业片 | 高密度高紧张杰出场景 | 交代角色+建立类型基调 |
| 文艺片 | 风格化段落，不必紧张 | 前2分钟感受"这部电影不一样" |
| 短片 | 前15秒"不太对"的日常 | 第一个画面就含信息或悬念 |
| 剧集冷开场 | 每集必须有，第一集最重 | 建立世界观+角色+类型+季度冲突种子 |

**"不太对"的日常**（短片黄金公式）：看起来正常，某个细节让人起疑。

## 九、选题五路径（引导式，不直接展示方法论）

| 路径 | 信号 | 引导问题 |
|------|------|---------|
| 从主题出发 | "关于孤独/记忆..." | "什么人在什么处境下被逼做选择？" |
| 从人物出发 | "我想写一个XX样的人" | "这个人最害怕什么？逼他面对会怎样？" |
| 从空间出发 | 给了具体地点 | "谁在上面谁在下面？什么资源稀缺？" |
| 从关系出发 | "两个人之间的故事" | "两人的Want为什么不可能同时实现？" |
| 从标签碰撞 | 给了几个关键词 | 使用概念组合五种方法（见 structures.md）|

## 十、概念组合五种方法（创意发想工具）

| 方法 | 定义 | 示例 |
|------|------|------|
| **概念嫁接** | A的机制 + B的场景 | 斩杀线+AI焦虑="员工分数低于线，工位上只剩USB" |
| **时空错置** | A放进不属于它的时代/地点 | 外卖骑手+古代驿站="八百里加急超时扣星" |
| **隐喻具象化** | 抽象焦虑变成物理规则 | 内卷="灯必须比邻居亮，亮度不够就断电" |
| **反转并置** | 两个对立事物放在同一场景 | 宠物+畜牧="精心喂猫，旁边是屠宰场" |
| **规则反转** | 把现实规则取反 | 越努力越成功→反转="越努力拥有越少" |

## 十一、工作流八步（通用，不同格式缩放）

```
1. 破题与核心动作 — 确立故事的"核"（戏剧动作/高概念）
2. 梗概草稿 — 一段话故事提要
3. 人物深度与弧光 — Want/Need/Ghost/Lie/Flaw
4. 前史与世界观 — 完整世界建造（长内容必须充分展开）
5. 结构大纲 — 骨架，含开场钩子设计
6. 场景拆解 — 大纲转化为视听单元
7. 场景写作 — 填充血肉，执行视觉写作和潜台词
8. 剧本医生 — 诊断与抛光

格式缩放：概念超短片可跳过4、6；剧集需在步骤前加"季度规划+分集大纲"
```

## 十二、跨格式技法借鉴地图

| 借鉴来源 | 技法 | 应用在 |
|---------|------|-------|
| 概念片 | 高概念翻转 | 任何格式的单场戏punch |
| 概念片 | 零解释纯视觉建立 | 长片/剧集引入新规则的场景 |
| 短片 | McKee价值转变 | 检验任何格式的每场戏 |
| 长片 | Ghost/Lie/Flaw | 简化后用在短片人物 |
| 剧集 | 集末钩子逻辑 | 长片的序列衔接 |
| 剧集 | 信息释放时间表 | 长片的世界观管理 |
