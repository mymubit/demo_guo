## P0 熔断红线（直接否决，不可妥协）

以下任意一项命中，整部剧无法通过审核，**立即停止创作**：

```
人口买卖相关：拐卖/人口买卖/买孩子/卖女儿
未成年人犯罪：未成年+犯罪语境/小学生+杀
恐怖内容（详见下方分级）
极端性暴力展示
```

### 恐怖内容P0分级

| 分级 | 内容 | 处置 |
|------|------|------|
| 极端级（直接熔断） | 活体解剖、食人、长时间酷刑+展示 | 立即否决 |
| 高风险 | 真实犯罪手法详细演示、惊悚意象密集 | 强制删改 |
| 中风险 | 孤立的恐怖场景（无系统渲染） | 建议修改 |

## P1 强制修改项

以下问题**必须修改**才能通过：

```
敏感职业身份（无正义收束）：通缉犯/恐怖分子
极端家庭关系：乱伦/虐待儿童
犯罪手法详细展示（无法律收束）
反派洗白（有犯罪无正义惩罚）
```

## P2 建议优化项

以下问题建议但不强制修改：

```
灰色地带职业（高利贷/地下赌场）：建议增加危害说明
过度暴力描写（未触P0）：建议淡化细节
```

## 犯罪正义收束规则（熔断级硬约束）

### 触发条件

```
当剧本满足以下条件时，必须有正义收束：
- 涉及犯罪词汇≥2处（谋杀/绑架/诈骗/黑社会等）
- 结尾段落（最后35%剧情）

常见犯罪触发词：
犯罪/违法/谋杀/杀害/绑架/诈骗/勒索/抢劫/盗窃/贩毒/
行贿/受贿/潜逃/灭口/栽赃/黑恶势力/非法集资/贪污...
```

### 正义收束标准

```
高犯罪密度（≥5处）：全剧至少3处正义词汇
普通犯罪密度：全剧至少2处正义词汇
结尾段落：至少1处正义词汇

正义词汇示例：
受到惩罚/法律制裁/伏法/判刑/军法处置/
下旨查办/认罪/缉拿归案/正义得到伸张...
```

### 洗白检测（强制触发）

以下词汇出现时，必须同时出现正义词汇：

```
洗白标记词：洗白/情有可原/不得已/其实他也是受害者/
           被迫害才/社会对他不公/早期救赎/获得原谅/值得同情
```

## 九维风险评估

审核剧本时，从以下9个维度评估风险：

| 维度 | 检测重点 |
|------|---------|
| 1. 价值观 | 是否美化犯罪/反社会行为 |
| 2. 人物塑造 | 反派是否有足够负面形象 |
| 3. 未成年保护 | 是否涉及未成年人敏感内容 |
| 4. 版权风险 | 是否与知名IP高度相似 |
| 5. 社会敏感 | 是否涉及敏感群体/事件 |
| 6. 虚假宣传 | 是否有夸大不实内容 |
| 7. 恐怖内容 | 暴力/恐怖程度 |
| 8. 犯罪展示 | 犯罪手法是否详细展示 |
| 9. 平台红线 | 各平台的专项禁止内容 |

## 三阶段合规清单

### 立项阶段（`drama.compliance-guard` 执行）

```
□ 题材不触P0红线
□ 无高版权风险（不与知名IP高度相似）
□ 核心冲突无社会敏感点
```

### 创作阶段（逐集gate检测）

```
□ 无P0触发词
□ 涉犯罪内容有正义收束铺垫
□ 未成年角色处于安全情境
```

### 交付阶段（`drama.compliance-guard` 执行）

```
□ 完整合规检测（P0/P1/P2三级）
□ 犯罪正义收束验证（高犯罪剧必须≥2处正义词汇）
□ 九维风险评估完成
□ 备案材料清单齐全：
  - 完整剧本（03_完整剧本/ 或交付包）
  - 世界观与人设（02_项目设定/ 或交付包第一部分）
  - 分集大纲/故事梗概
  - 质量报告（04_评估报告/质量报告.json）
  - AI生成内容标识（按平台要求）
```
