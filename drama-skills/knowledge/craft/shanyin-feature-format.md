## 结构选型指南

| 题材/意图 | 推荐方法论 | 核心逻辑 |
|----------|-----------|---------|
| 商业类型片（动作/惊悚/喜剧）| **Save the Cat 15节拍** | 节拍精确到分钟，严格节奏控制 |
| 成长/冒险/变形记 | **Dan Harmon Story Circle** | 八步圆环，天然适合英雄旅程 |
| 角色复杂、主题先行 | **McKee 故事原理** | 价值转变为核心，深度戏剧 |
| 角色驱动文艺片 | **内在节拍表** | 节拍是内心状态转变而非外部事件 |

## Save the Cat 15节拍（短剧适配版）

将100分钟长片节拍映射到N集短剧：

```
第一幕（约15%集数）：
  1. Opening Image — 开场画面：展示角色旧世界，与Final Image形成对照
  2. Theme Stated（约第5%集）— 某角色无意说出本剧主题
  3. Set-Up（前10%）— 主角日常/缺陷/世界/关系铺设
  4. Catalyst（约第12%集）— 打破平衡的不可逆事件
  5. Debate（12-25%）— 主角犹豫：接不接受挑战（体现Flaw）

第二幕前半（约30%集数）：
  6. Break into Two（约第25%集）— 主角做决定，进入新世界
  7. B Story（引入副线）— 通常是新关系，承载主题论点
  8. Fun and Games（30-55%）— 用旧方法应对新问题，有成有败

中点（约第50-55%集）：
  9. Midpoint — 伪胜利或伪失败，赌注从个人升至更大层面

第二幕后半（约30%集数）：
  10. Bad Guys Close In（55-75%）— 内外压力收紧，Flaw产生代价
  11. All Is Lost（约75%集）— 最低点：失去最重要的东西
  12. Dark Night of the Soul（75-85%）— 直面Lie/Ghost，弧光临界点

第三幕（约15%集数）：
  13. Break into Three（约85%）— 想通了，A/B认知融合
  14. Finale（85-100%）— 五步：集结→执行→高塔惊魂→挖掘内心→新计划
  15. Final Image — 与Opening Image对照，展示新常态
```

## Dan Harmon Story Circle（八步圆环）

```
1. YOU — 角色在舒适区（建立常态）
2. NEED — 角色产生欲望（可以是外在目标或内在渴望）
3. GO — 进入不熟悉的处境（不可逆决定）
4. SEARCH — 寻找/适应/挣扎（用旧方法应对新问题）
5. FIND — 得到想要的东西（但会带来代价）
6. TAKE — 为所得之物付出代价（圆环底部，距舒适区最远）
7. RETURN — 回到熟悉处境（物理或心理上）
8. CHANGE — 展示变化后的新常态（与Step 1对照）

核心美感：回到起点但已经不同
特别适合：成长故事、冒险、变形记
```

## McKee 故事原理（价值转变核心）

```
控制性理念：[价值] + [原因]
  "正义获胜，因为主角愿意牺牲自己珍视的一切"

核心工具——价值转变（每场戏必用）：
  场景开始时的核心价值状态 → 场景结束时的状态
  如果价值状态没有转变 → 这场戏应该被删除

鸿沟（The Gap）：
  角色期望的结果 vs 实际得到的结果
  鸿沟越大 = 戏剧张力越强

进展纠葛：冲突必须逐步升级（内外部同步深化）

危机选择：真正的两难（两害取其轻 或 两善不可兼得）
```

## 文艺片内在节拍 + 五种风格变体

| 变体 | 代表作气质 | 核心特征 |
|------|----------|---------|
| **是枝裕和式** | 步履不停/小偷家族 | 极慢建置/日常动作即叙事/情感不被放大/沉默有分量 |
| **王家卫式** | 重庆森林/花样年华 | 情绪连接场景/旁白与画面错位/重复母题/时间是主角 |
| **小津安二郎式** | 东京物语/晚春 | 极低机位固定/枕镜头停顿/克制即潜台词/接受而非欢喜 |
| **Linklater式** | 爱在黎明破晓前 | 对话本身就是故事/跑题+绕回/通过聊什么暗示内心 |
| **奉俊昊式** | 寄生虫/杀人回忆 | 商业骨架+社会批判/前后类型突变/空间即隐喻/细节多义性 |

## Ghost/Lie/Flaw人物链条（长片级，短剧可用）

```
Ghost（前史创伤）→ Lie（错误信念）→ Flaw（行为模式）

完整弧光链：
Ghost → Lie → Flaw → Want（错误追求）
→ 一系列考验 → 面对Need → 关键选择（坚持Lie还是拥抱Need）
→ 新常态

示例：
Ghost = 被最信任的人背叛
Lie = "不能信任任何人"
Flaw = 推开每一个试图靠近的人
Want = 独自完成任务（错误目标）
Need = 学会信任与被信任（真正需要的）
```

## 伏笔登记表（模板）

```
伏笔内容 | 层次 | 首次出现位置 | 回扣位置 | 回扣如何改变含义
---------|------|------------|---------|----------------
[道具/台词/行为/结构伏笔] | ... | 第X集第Y场 | 第A集 | [原含义→新含义]
```

**规则**：
- 伏笔首次出现不能太刻意（观众不应意识到"这是伏笔"）
- 每个伏笔都必须有回扣（没有回扣的是烂尾）
- 长片至少3-5个伏笔/回扣对，分布在不同层次

## 次要角色四种功能

| 功能 | 定义 | 举例 |
|------|------|------|
| **镜像角色** | 走了主角没走的路 | "如果主角不同选择，就会变成这个人" |
| **催化角色** | 推动主角变化的外力 | 导师/诱惑者/挑战者 |
| **主题角色** | 具象化主题论点的某立场 | B Story通常是这个功能 |
| **节奏角色** | 提供喜剧relief，情绪调剂 | 让观众在紧张段落有地方喘气 |
