## 剧集与短剧的关键差异

| 维度 | 长片/电影 | 剧集 | 短剧（我们的主场景）|
|------|---------|------|---------------|
| 弧光 | 一次完整旅程 | **预算制**（分配到各集）| 紧凑弧光，30集内完成 |
| 世界观 | 一次搭建完 | **分层释放** | 前3集建立核心规则即可 |
| 单集独立性 | 不适用 | 70-100%取决于类型 | 每集必须独立好看 |

## 双层结构（集内 + 季度）

### 层一：集内结构（四段式，与短剧一致）

```
冷开场/开场钩子（每集必须有，不只是第一集）
├── 商业剧集：高张力场景直接扔进紧张
├── 悬疑/单元剧：看似无关但集末回扣的独立切片
├── 连续剧：上集cliff-hanger的延续解决
└── 文艺剧集：高度风格化段落锚定本集情绪基调

第一集冷开场最重：同时建立世界观+角色+类型基调+季度冲突种子
```

### 层二：季度弧线（四阶段）

| 阶段 | 集数比例 | 核心任务 |
|------|---------|---------|
| 建置 | 前25% | 世界观表层+Want/Lie建立+关系网搭建+冲突种子 |
| 发展 | 25%-65% | 冲突升级+运行逻辑揭示+多次伪变化 |
| 危机 | 65%-85% | 一切尽失+面对Ghost/Lie+最重要关系破裂 |
| 高潮落幕 | 后15% | 底层真相揭示+关键选择+弧光完成 |

**适配示例**：

| 总集数 | 建置 | 发展 | 危机 | 高潮 |
|--------|------|------|------|------|
| 20集 | E1-5 | E6-13 | E14-17 | E18-20 |
| 30集 | E1-8 | E9-20 | E21-26 | E27-30 |
| 50集 | E1-13 | E14-33 | E34-43 | E44-50 |

## 弧光预算分配（短剧必用）

```
角色：[名字]
季度弧光：从[A状态] → 到[B状态]
Lie：[角色相信的谎言]
总集数：N

弧光预算规则：
- 前25%集数：累计进度不超过15%（不要太快）
- 65%-85%位置是加速区（变化量最大）
- 至少1次伪变化后的回退（在40%-60%位置）
- 每集不是都需要弧光事件——有些集角色不变化也可以
```

## 世界观信息释放时间表（按比例）

```
信息层       | 释放位置    | 释放方式
------------|-----------|----------
表层规则     | 前10-15%  | 直接展示（E1-2）
表层细节     | 15-30%    | 角色遭遇/B Plot
运行逻辑     | 40-55%    | 角色调查/发现
逻辑延伸     | 55-75%    | 关系对话中泄露
底层真相     | 最后20%   | 高潮揭示
伏笔回扣     | 最后1-2集  | 观众恍然大悟
```

**核心原则**：每层信息通过角色行动呈现，不通过旁白/字幕解释。每集最多展示一个新层。

## 伏笔密度建议

| 类型 | 频率 |
|------|------|
| 集内伏笔 | 每集至少1个 |
| 短程伏笔（跨1-3集） | 每3集至少1个在回扣 |
| 长程伏笔（跨5集+） | 整季至少2-3个 |
| 季度伏笔 | 至少1个（最强力） |

## 分集大纲模板

```markdown
第[X]集《集名》

【集内核心】
一句话故事（Logline）：
本集核心戏剧动作：目标 → 阻碍 → 结果
本集情绪基调：建置型/轻快型/紧张型/呼吸型/转折型/崩塌型/高潮型

【集内结构】（含时长预算）
冷开场/开场钩子（约Xs）：[这段开场单独拿出来是否精彩？]
建置（约X分钟）：情节[松/中/紧] | 情感[轻/中/重]
发展（约X分钟）：障碍1 → 障碍2 →
高潮（约X分钟）：情节[松/中/紧] | 情感[轻/中/重]
结局+集末钩子（约X分钟）：

【季度连接】
弧光预算消耗：本集角色变化了什么？累计进度？
暗线推进：本集推进了哪条暗线？
世界观释放：本集是否释放新信息层？
埋种：[种子内容] → 计划E[X]回收
回调：回收了之前哪些种子？

【集间关系】
承接上集：从什么状态开始？
递交下集：结束时留了什么？
节奏对比：本集vs上集/下集的情节/情感强度？
```

## 连续性管理系统（四张追踪表）

每集完成后立即更新：

### A. 角色状态追踪
```
角色 | 本集结束状态 | 关键变化 | 下集需延续的点
```

### B. 暗线进度追踪
```
暗线名称 | 当前进度 | 本集推进 | 下次推进计划（哪集）
```

### C. 埋种/回调登记
```
种子内容 | 埋入集数 | 计划回调集 | 回调方式 | 已回调？✅/❌
```

### D. 已公开信息清单
```
信息内容 | 公开集 | 公开方式 | 谁知道 | 谁不知道
```

## 集间节奏管理（情绪基调波浪）

```
参考节奏模板（按比例）：
前10%：建置 → 10-20%：轻快/建置 → 20-30%：第一次紧张
30-40%：呼吸 → 40-50%：转折（中段大事件）→ 50-60%：过渡升级
60-70%：压力 → 70-75%：呼吸或伪高潮 → 75-85%：崩塌/至暗
85-95%：反击 → 最后5-10%：高潮+落幕

规则：
- 不能连续3集以上同一基调
- 紧张/压力集之后至少1集呼吸
- 呼吸集不是废集——让角色关系深化、B Plot推进
```

## 剧集常见陷阱（避坑清单）

- ❌ 跳过分集大纲直接写单集 → 必须先拉通全季
- ❌ 为季度弧线牺牲单集精彩度 → 每集拆出来必须好看
- ❌ 弧光预算失控（前面变化太大，后面无处可去）→ 严格遵守比例
- ❌ 连续性错误 → 每集开写前查追踪表
- ❌ 集末钩子强行制造冲突 → 钩子必须是本集故事的自然延伸
- ❌ 情节和情感节奏始终同步 → 刻意制造"松+重"错位
- ❌ 伏笔埋了忘记回扣 → 用埋种/回调登记表审计
