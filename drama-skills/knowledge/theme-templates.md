## 参数说明

### 反转密度（reversal_density）
每集平均反转次数的参考值。
- 0.15 = 每7集约1次反转（疗愈类轻缓节奏）
- 0.35 = 每3集约1次反转（复仇类适中节奏）
- 0.60 = 每2集约1次甚至更多（悬疑类高密度）

### 情绪曲线（emotion_curve [8节点]）
对应单集四段式8个固定节点的目标情绪值（1-10）。

```
节点含义：
1 = 开场钩子     2 = 情境建立初    3 = 情境建立末
4 = 第一冲突     5 = 情绪升级      6 = 情绪峰值
7 = 情绪余震     8 = 集末悬念
```

## 混合题材使用指引

```
常见混合：
  甜宠 + 悬疑 → 主情感线(60%) + 谜题线(40%)
  复仇 + 甜宠 → 先虐后甜，情感作为复仇的动力
  穿越 + 权谋 → 先知先觉的智谋对决

参数融合方法：
  反转密度 = 加权平均（按主次题材比例）
  情绪曲线 = 选择主题材的曲线，在次题材的关键情绪点提升
```
