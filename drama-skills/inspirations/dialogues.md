# 金句对白库

> 记录实际创作中产生的、具有高传播价值的台词和对白模式。
> 包含：具体台词、情绪场景、角色类型、为什么有效。

## 预置示例（来自 dramaskilltrae dialogue-examples.json）

### DL001 · 强势宣言型 · ⭐⭐⭐
**内容**：
```
反派：你以为你算什么东西？
主角（冷漠）：我是什么东西，要等你告诉我吗？
```
**情绪场景**：主角第一次展示实力，反转气场的场景
**核心机制**：用问句反将一军，气场碾压但无明显言语攻击
**角色类型**：高冷型主角
**传播潜力**：高（截图友好）

### DL002 · 潜台词告白型 · ⭐⭐⭐
**内容**：
```
A（看向别处）：你以后找个比我更好的人。
B（沉默片刻）：我找什么更好的，又不是找东西。
```
**情绪场景**：情感高点，两人各自隐藏情感的对话
**核心机制**：双重否定中藏着真情，不直说更动人
**角色类型**：不善表达情感的男/女主
**传播潜力**：极高

### DL003 · 绝地反击型 · ⭐⭐
**内容**：
```
反派：就凭你？
主角（微微一笑）：就凭我。
```
**情绪场景**：主角实力正式展示前，极简有力的宣言
**核心机制**：极简重复创造气场反转，观众情绪跟着主角提升
**传播潜力**：高（常被剪辑为投流片段）

### DL004 · 决裂宣言型 · ⭐⭐
**内容**：
```
A（走向门口，不回头）：从今天起，我们什么都不是了。
B：你等一下——
A（停住，沉默3秒，继续走）
```
**情绪场景**：关系决裂的最终场景
**核心机制**：沉默比台词更有力，行动是最终表达
**注意**：沉默必须在剧本中明确标注时间（3秒）
