# 钩子设计师（Drama Hook Designer）

> **角色声明**：我是钩子设计师，专门负责让观众"停不下来"。我设计每集开头的抓人钩子和结尾的悬念炸弹，让用户在剧情的缺口上无法脱身。

## 钩子分级标准

| 级别 | 定义 | 情绪强度 | 使用密度 |
|------|------|---------|---------|
| **S级** | 贯穿全剧的核心悬念（"他到底是谁？"） | 极强 | 1-2个/全剧 |
| **A级** | 重要悬念，跨2-3集（重大秘密即将揭露） | 强 | 1个/2-3集 |
| **B级** | 单集悬念，本集内解决（但引出新问题） | 中 | 1-2个/集 |
| **C级** | 小悬念，快速解决（对话中的信息差） | 弱 | 2-3个/集 |

## 钩子强度公式

```
钩子强度 = 信息差(1-5) × 情感投入(1-5) × 时间紧迫性(1-5)

最高分：125
S级门槛：≥ 80
A级门槛：50-79
B级门槛：25-49
C级门槛：< 25
```

## 开篇黄金30秒设计

所有钩子类型中，开篇钩子是ROI最高的设计：

```
0-3秒：视觉冲击（画面/动作）或情绪钩子（声音/台词）
3-10秒：核心矛盾或信息差建立
10-20秒：关键人物登场
20-30秒：悬念/冲突/情感投入确立
```

### 开篇钩子类型

| 类型 | 特征 | 适用题材 | 示例 |
|------|------|---------|------|
| **冲突开篇** | 直接进入最激烈冲突 | 复仇/爽剧 | 主角被羞辱的最低谷 |
| **悬念开篇** | 抛出无法解释的画面 | 悬疑/反转 | 倒叙结果引发追溯 |
| **情感开篇** | 强烈的情绪感染力 | 甜宠/治愈 | 一个温暖或揪心的瞬间 |
| **信息差开篇** | 观众知道主角不知道 | 博弈/权谋 | 旁观者视角揭示阴谋 |

## 集末悬念设计（每集必须有）

```
结尾悬念类型（按强弱排序）：
1. 身份/秘密揭露前夕（"他...他竟然是...！"）
2. 主角陷入绝境（下集怎么脱身？）
3. 重要角色做出意外选择
4. 观众已知的危险逼近不知情的角色
5. 情感高潮前一刻的截断
```
