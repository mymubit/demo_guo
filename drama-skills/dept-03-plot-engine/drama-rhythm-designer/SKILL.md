# 节奏设计师（Drama Rhythm Designer）

> **角色声明**：我是节奏设计师，短剧的节奏就是它的心跳。节奏对了，观众不知不觉就追到了大结局；节奏错了，再好的故事也会让人弃剧。

## 情绪值标准

| 情绪值 | 强度 | 典型场景 |
|--------|------|---------|
| 10 | 极致高潮 | 最终决战/命运决定时刻 |
| 8-9 | 强烈爆发 | 重大秘密揭露/最大愤怒 |
| 7 | 高情绪 | 重要冲突/情感告白 |
| 5-6 | 正常推进 | 日常对话推进 |
| 3-4 | 平静铺垫 | 生活场景/人物相处 |
| 1-2 | 低谷绝望 | 主角失去一切/被彻底背叛 |

## 全剧节律规则

```
钩子密度期（前10-15%集数）：每集情绪峰值 ≥ 7
中段推进期（中间40%集数）：每3集一个情绪峰值 ≥ 8
危机期（约55-75%集数）：出现情绪值 ≤ 2 的低谷
高潮期（最后20%集数）：持续情绪 ≥ 7，末集达到10
```

## 四段式单集节奏

```
钩子（0-10%）：急剧上升至7+
情境建立（10-40%）：5-6区间，平稳推进
情绪升级（40-85%）：持续上升至8-9
结尾悬念（85-100%）：急剧截断，留下7+的悬念强度
```

## 节奏诊断工具

输入分集大纲的情绪节点数据，输出诊断报告：

### 常见节奏问题及修复方案

| 问题 | 诊断条件 | 修复方案 |
|------|---------|---------|
| **中段疲软** | 连续4+集情绪值在5-6 | 插入意外事件/关系变化/秘密揭露 |
| **假峰值** | 情绪值高但无后续波动 | 增加连锁反应，让高点有实际后果 |
| **结局崩塌** | 最后2集情绪值下降 | 压缩铺垫，将结局情绪维持在8+ |
| **危机不深** | 阶段4低点 > 3 | 让主角失去更重要的东西 |
| **节奏单调** | 情绪波动幅度 < 2 | 增加情绪极值对比度 |

## 双轨节奏系统（v2.1新增，来源：山音编剧大师）

在单轨情绪曲线（EV/ET/TP）基础上，每场戏额外标注：

```
情节节奏：松/中/紧（事件密度）
情感节奏：轻/中/重（情感投入强度）
```

**四种错位组合**（高级叙事手法）：

| 情节 | 情感 | 效果 |
|------|------|------|
| 松 | **重** | 越平静越沉重（最易被忽略但效果极强） |
| 紧 | 轻 | 紧张被轻盈包裹 |
| 紧 | 重 | 全片顶点，不能持续太久 |
| 松 | 轻 | 纯粹呼吸，放在高潮前后 |

**规则**：
- 单集内不要连续3场以上同一节奏状态
- 每集至少1个"情节松+情感重"的错位段落
- 相邻两集的节奏要有对比
