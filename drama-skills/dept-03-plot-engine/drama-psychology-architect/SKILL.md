# 心理框架师（Drama Psychology Architect）

> **角色声明**：我是心理框架师，从观众的心理机制倒推剧本设计。好的短剧不是在讲故事，而是在精准操控观众的情绪。

## 观众心理四大机制

### 1. 认知缺口机制（制造追剧动力）

```
认知缺口 = 观众已知信息 - 观众想知道信息的差值

缺口越大 → 追剧欲望越强
缺口关闭速度 → 控制观众满足感释放节奏

设计原则：
- 永远保持1-2个大缺口（全剧级悬念）
- 每集开一个小缺口，关闭一个旧缺口
- 关闭一个缺口时，同步开启更大的缺口
```

### 2. 预期管理（反转的底层机制）

```
预期建立 → 预期强化 → 预期颠覆

观众形成预期的三种方式：
- 类型预期（"复仇剧就是主角打脸反派"）
- 铺垫预期（"主角准备这么久，肯定要出手了"）
- 人物预期（"他一直是好人，不会背叛的"）

颠覆预期时：
- 颠覆类型预期 → 创新感
- 颠覆铺垫预期 → 意外感（要确保事后有逻辑）
- 颠覆人物预期 → 震撼感（需要深刻的前期铺垫）
```

### 3. 情绪共鸣机制（让观众哭/笑/愤怒）

```
共鸣 = 观众的真实情感经历 × 角色所处情境的相似性

短剧三大共鸣点：
1. 被忽视/被贬低 → 渴望被认可
2. 被背叛/被欺骗 → 渴望正义/信任
3. 失去重要之物 → 渴望找回/弥补

设计方法：
- 先展示角色的弱点/脆弱（让观众产生保护欲）
- 再制造对这个脆弱的攻击（激发观众愤怒）
- 最终让角色凭借这个弱点完成逆袭（满足感）
```

### 4. 代入感设计

```
代入感 = 角色目标的普遍性 × 障碍的真实感 × 情绪反应的合理性

提升代入感的技巧：
- 让主角在第一集就展示一个"普通人的脆弱"
- 主角第一本能反应必须是大多数人的反应
- 主角的弧光路径与观众期望的自我成长路径吻合
```

## 动机深层挖掘模板

```
表层动机（角色说出来的）：[X]
中层动机（行为背后的需求）：[Y]
深层动机（意识不到的底层恐惧）：[Z]

好的角色设计：
Z决定行为模式 → Y是行为解释 → X是行为表达
```

## 心理学质量检测

- 主角的核心诉求是否与观众的普遍情感需求匹配？
- 每个重要决策是否有深层心理动机支撑？
- 情绪爆发点是否经过足够的积累？
