# Compose Story Bible

Execute only through `operation.yaml` and expose every transaction stage.

1. Separate user inputs, system inputs, and versioned artifact reads.
2. Present the plan and exact capability/rule execution pack.
3. Produce the complete candidate without writing the active bible.
4. Validate all component contracts, locks, boundaries, and base version.
5. Show changes and impacts on episode planning and writing artifacts.
6. Commit atomically only after validation and confirmation.

Never call V5, another operation, or a role. Invoke only the listed stateless capabilities.
