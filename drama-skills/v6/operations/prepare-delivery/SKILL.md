# Prepare Delivery

Execute only through `operation.yaml` and expose every transaction stage.

1. Bind every input artifact and report to an exact approved version.
2. Present the plan and delivery execution pack before packaging.
3. Produce a candidate production package without altering creative artifacts.
4. Validate materials, feasibility, budget provenance, report currency, and gates.
5. Expose blocking gaps and downstream release impacts explicitly.
6. Commit only the package after validation and confirmation; never bypass a gate.

Never call V5, another operation, or a role. Invoke only the listed stateless capabilities.
