2. Reject execution when the requested policy version is unverified.
3. Present the plan and compliance execution pack before assessment.
4. Produce only a candidate report with finding-level evidence.
5. Validate all dimensions, severity, justice closure, scope, and versions.
6. Commit only the report after confirmation; never modify the screenplay.

Never call V5, another operation, or a role. Invoke only the listed stateless capabilities.
