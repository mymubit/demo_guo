## 1. 商业剧本格式速查（来源：natural-script-standard.md）

### 场景头
```
集号-镜头号 时间 内外 地点
1-1 日 外 朱雀门楼
5-3 夜 内 出租屋
```

### 人物列表
```
人物：夏倾凰、秦桧、侍卫（群）
```

### 动作标记（△符号）
```
△【全景】残阳如血，朱雀门楼上，夏倾凰的铠甲泛着冷光。
△【特写】她手指轻抚剑柄，眼神如冰。
```

### 台词格式
```
秦桧（阴冷）：陛下，镇北王拥兵自重，此女断不可留。
夏倾凰（冷笑）：秦相国说的是你自己吧？
```

**禁止事项**：
- 禁止台词使用引号
- 禁止方括号场景头（如`【第一场】`）
- 禁止独立`【画面】`/`【镜头】`行
- 禁止无镜头号场头

## 2. 单集四段式结构（来源：episode-structure-template.md）

| 段落 | 时长占比 | 核心目标 | 情绪曲线 |
|------|----------|----------|----------|
| 钩子（Hook） | 0-10% | 3秒内抓住注意力，制造强烈悬念 | 急剧上升 |
| 情境建立 | 10-40% | 交代背景，铺垫冲突 | 平稳推进 |
| 情绪升级 | 40-85% | 矛盾激化，情绪峰值 | 持续上升→峰值 |
| 结尾悬念 | 85-100% | 开放式结局，引发下集期待 | 急剧下落→悬念钩 |

**钩子类型（必选其一）**：
- 反转钩：呈现结果，倒叙原因
- 冲突钩：直接展示最激烈矛盾点
- 秘密钩：揭示隐藏信息

## 3. 六阶段叙事结构（来源：natural-script-standard.md）

| 阶段 | 集数范围（30集示例） | 核心任务 |
|------|---------------------|----------|
| 1. 建立世界 | 1-5集 | 主角登场、世界规则、初始渴望 |
| 2. 冲突引入 | 6-10集 | 核心矛盾曝光、势力对立 |
| 3. 升级对抗 | 11-18集 | 主角成长、障碍升级、关系变化 |
| 4. 危机爆发 | 19-22集 | 最大反转、主角跌至谷底 |
| 5. 决战前夕 | 23-26集 | 资源整合、决心重建 |
| 6. 最终对决 | 27-30集 | 高潮对决、结局收尾 |

## 4. 镜头语言速查（来源：camera-language-library.md）

### 景别使用规范
| 景别 | 适用场景 | 竖屏注意 |
|------|----------|----------|
| 大全景 | 环境交代，不超过3秒 | 人物须可识别 |
| 全景 | 人物全身动作 | 保持人物居中 |
| 中景 | 对话场景主力景别 | 腰部以上 |
| 近景 | 情绪传达、重要台词 | 胸部以上 |
| 特写 | 情绪高峰、关键道具 | 面部填满画面 |
| 大特写 | 极致情绪峰值 | 谨慎使用 |

### 情绪-镜头对应
| 情绪状态 | 推荐镜头 |
|----------|----------|
| 愤怒/激动 | 特写→大特写，手持晃动感 |
| 悲伤/无助 | 近景，慢推，低机位 |
| 威胁/压迫 | 仰角特写，快速推进 |
| 暧昧/心动 | 浅景深近景，慢速移动 |
| 对峙/博弈 | 正反打切换，相当切割 |

## 5. 情绪曲线标准（来源：emotion-curve-template.md）

### 单集情绪节点（必须标注）
每集大纲中须标注：
- **情绪峰值**（EV）：本集最高情绪点，情绪值8-10
- **情绪低谷**（ET）：本集最低情绪点，情绪值1-3  
- **转折点**（TP）：情绪方向发生变化的节点

### 情绪值定义
```
10 = 极致高潮（主角命运决定性时刻）
8-9 = 强烈冲突/情感爆发
5-7 = 日常情绪波动（对话推进）
3-4 = 平静/铺垫
1-2 = 低谷/绝望
```

## 6. 竖屏分镜规范（来源：storyboard-vertical-template.md）

### 分镜表格式
```markdown
| 镜号 | 景别 | 内容描述 | 时长 | 台词/音效 |
|------|------|----------|------|-----------|
| 1-1  | 全景 | △场景描述 | 3s  | 无 |
| 1-2  | 近景 | △动作描述 | 4s  | 角色（情绪）：台词 |
```

### AI图像生成提示词规范（供AI工具使用）
```
[镜号]-[景别], [主体描述], [情绪状态], [光线/氛围], 竖屏9:16, 电影感, 高清
示例：1-2-近景, 女主角愤怒表情, 强烈对抗情绪, 昏黄室内灯光, 竖屏9:16, 电影感, 高清
```

## 8. 质量评分维度（quality-reviewer 使用）

| 维度 | 权重 | 评分项 |
|------|------|--------|
| 格式规范 | 20% | 场景头、台词格式、△标记 |
| 结构完整性 | 25% | 六阶段覆盖、单集四段式 |
| 人物塑造 | 20% | 弧光清晰、性格一致、关系逻辑 |
| 情绪曲线 | 20% | 峰值节点、节奏起伏 |
| 商业可行性 | 15% | 平台适配、受众清晰、卖点突出 |

**评分输出格式**：
```json
{
  "overall_score": 82,

    "character": 75,
    "emotion": 85,
    "commercial": 80

  ],
  "recommendations": ["建议增加反派背景故事", "第15-18集节奏过缓需压缩"]
}
```
