## 后端检查清单

### 鉴权与授权

- [ ] 所有写操作接口配置 `IsAuthenticated` 或更严权限
- [ ] `get_queryset()` 按当前用户过滤，非超管不可查全量
- [ ] `get_object()` 校验资源归属，防 IDOR
- [ ] 管理接口与普通接口权限分离
- [ ] Token 过期、无效 Token 返回 401 而非 500

### 输入校验

- [ ] Serializer 校验类型、范围、必填、枚举
- [ ] 禁止客户端传入 `is_staff`、`role`、`user_id` 等待权字段（Mass Assignment）
- [ ] 文件上传：类型、大小、存储路径、病毒扫描（如适用）
- [ ] 原生 SQL 仅参数化查询

### 敏感数据

- [ ] 密码 `write_only=True`，响应不含 hash
- [ ] 日志不打印 Token、密码、支付密钥
- [ ] 异常处理不向前端返回 SQL/堆栈/内部路径
- [ ] 列表接口不返回不必要的 PII

### 接口与配置

- [ ] 调试/测试端点生产不可达
- [ ] 关键接口配置 throttle
- [ ] CORS 白名单最小化
- [ ] `DEBUG=False`，`ALLOWED_HOSTS` 正确
- [ ] `SECRET_KEY`、DB 密码来自环境变量

---

## 前端检查清单

### 鉴权

- [ ] 路由守卫与后端权限一致（不仅隐藏按钮）
- [ ] Token 存储方式安全（避免长期明文 localStorage 存敏感信息）
- [ ] 401 统一登出/刷新，不无限重试

### XSS 与渲染

- [ ] 用户输入展示经转义或使用安全组件
- [ ] 避免不可信的 `dangerouslySetInnerHTML`
- [ ] URL 参数不入 `eval`、动态脚本

### 敏感信息

- [ ] 控制台不打印 Token、完整错误堆栈
- [ ] 错误页不展示后端内部信息
- [ ] 支付/订单金额前端仅展示，不以前端值为准

## 常见漏洞模式

| 模式 | 示例 | 等级 |
|------|------|------|
| IDOR | `GET /api/orders/123/` 不校验 order.user == request.user | 高危 |
| 垂直越权 | 普通用户调用管理员-only 端点 | 高危 |
| Mass Assignment | 创建用户时 body 含 `"is_staff": true` | 高危 |
| 信息泄露 | 500 响应含 SQL 语句 | 中危 |
| 无 throttle | 登录接口可暴力破解 | 中危 |
| 前端-only 权限 | 仅隐藏按钮，接口仍可调用 | 高危 |

## 验证用例编号规范

| 前缀 | 含义 |
|------|------|
| SEC-AUTH | 鉴权与会话 |
| SEC-AUTHZ | 授权与越权 |
| SEC-INPUT | 输入与注入 |
| SEC-DATA | 敏感数据 |
| SEC-API | 接口暴露 |
| SEC-ENV | 生产配置 |

示例：

| 用例ID | 场景 | 步骤摘要 | 预期 |
|--------|------|----------|------|
| SEC-AUTHZ-001 | 水平越权 | 用户 A 访问用户 B 的订单详情 | 403/404 |
| SEC-INPUT-001 | XSS | 备注字段提交 `<script>alert(1)</script>` | 存储后展示为转义文本 |
