# 模块：九列分镜

> 挂载角色：`drama.revision-master`（修复稿附带分镜摘要）
> 方法论长文：`knowledge/production/shanyin-director-methodology.md`（基于 551 个真实镜头统计）

## 九列表格式

| 列 | 填写规范 |
|----|---------|
| 镜号 | 连续编号从 1 开始；多行对白只在第一行填写 |
| 时长 | `MM:SS-MM:SS`；最后一镜写 `MM:SS-结束` |
| 摄影角度 | 平视/俯拍/仰拍/微俯拍/极高俯拍 |
| 景别 | 大全景/全景/中景/中近景/近景/特写 |
| 画面内容 | 可见的视觉内容（角色动作/环境/效果） |
| 场景 | 场景名（与场景头一致） |
| 声音 | 对白/音效/环境声/配乐提示 |
| 备注 | 特殊拍摄要求 |
| 叙事目的 | 本镜头为什么存在（无目的镜头考虑删除） |

## 节奏基准

- 推进型镜头 2.5-3.5 秒；转折/情绪镜头 5-7 秒
- 竖屏 9:16：多用中近景/近景/特写，大全景仅场景建立时用
- 动作-反应镜头对：重大信息公布用「反应链」（动作→反应A→B→C）；悬疑场景可用「省略动作」（只拍反应）

## 执行步骤

1. 对修复稿每场输出九列表（摘要级：关键镜头即可，非逐秒分镜）
2. 每镜必填「叙事目的」；填不出目的的镜头回炉
3. 校验伏笔/回扣镜头成对出现；主题靠视听动作传达而非台词

## 自检清单

- [ ] 每场有九列摘要，镜号/时长连续
- [ ] 无「叙事目的」空白镜头
- [ ] 关键情绪镜头景别为近景/特写且时长 5-7s
