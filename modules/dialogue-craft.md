# 模块：首稿对白创作

## 目标
在首稿阶段写出有行动意图、人物区分度和潜台词的可表演对白。

## 输入
- 当前场景 Goal×Conflict
- 人物 `voice_tag`、关系状态和知识边界

## 引用规则
- `t1.global.dialogue_craft.intention`
- `t1.global.dialogue_craft.subtext`
- `t1.global.dialogue_craft.scene-rhythm`
- `t1.global.dialogue_quality.voice-by-class`
- `t1.global.ai_tone_forbidden.core`

## 输出
- 场景对白
- 关键台词的行动意图与潜台词自检

## 执行步骤
1. 写清双方想从对话中获得或隐藏什么。
2. 按人物声音、权力位置和情绪节奏选择表达方式。
3. 让打断、停顿、回避和称谓随上风变化。
4. 删除解释设定、重复已知信息和无行动作用的问答。

## 失败条件
- 遮住角色名后无法判断说话者。
- 角色直接说出真实欲望或替作者解释主题。

## 自检清单
- [ ] 每句关键台词有明确行动意图
- [ ] 关键情感场景存在潜台词
- [ ] 朗读后自然且可表演
