# 模块：核心概念形成

## 目标
把主题、人物、空间、关系或标签输入收敛为一个可讲、可拍、可持续升级的核心概念。

## 输入
- `core_idea` 或用户原始描述
- 目标受众、题材与篇幅约束

## 引用规则
- `t1.global.concept.entry-paths`
- `t1.global.concept.combination-methods`
- `t1.global.concept.elevator-test`
- `t1.global.philosophy.cross-section`

## 输出
- `core_idea`
- `core_conflict`
- `hook_concept`
- 一句话电梯陈述

## 执行步骤
1. 判断创意入口并提取不可替代的冲突核。
2. 必要时只选一种概念组合法增强差异化。
3. 写出“主角身份—急切目标—核心阻碍—独特机制”。
4. 用横截面检验开场是否能直接进入最大张力。

## 失败条件
- 只能描述题材，无法说明角色必须做出的选择。
- 删除专有名词后与常见故事没有差异。

## 自检清单
- [ ] 只有一个主戏剧动作
- [ ] 概念可通过可见行动呈现
- [ ] 一句话同时包含目标、阻碍与差异化机制
