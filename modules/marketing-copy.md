# 模块：营销文案

> 挂载角色：`drama.delivery-tool`（投流与平台文案）

## 平台差异化策略

| 平台 | 标题风格 | 侧重 |
|------|---------|------|
| 抖音 | 强钩子悬念，前 5 字定生死 | 冲突前置、身份反差 |
| 快手 | 情感共鸣、接地气 | 人物命运、情义 |
| 微信小程序 | 剧情浓缩+付费诱导 | 「看到第 N 集我哭了」式种草 |

## 交付物清单

1. **剧名备选**：3 个，每个 ≤8 字，含题材关键词或身份反差
2. **15 字悬念标题 ×3**：句式参考「她 XX 的那天，全城 XX」「没人知道，XX 其实是 XX」
3. **平台简介**：50-80 字，止于第一个大反转前，末句必须是问句或悬念
4. **投流短视频脚本**（0-3-8-15 秒结构）：
   ```
   0-3s   最强冲突画面（可直接用第 1 集黄金 3 秒）
   3-8s   身份/关系信息差抛出
   8-15s  悬念定格 + 「完整版看主页」
   ```
5. **高光切片建议**：从 quality_report 高分集中选 3 个切片点（冲突峰值/反转揭露/金句场景）

## 自检清单

- [ ] 标题/简介不剧透 S 级反转
- [ ] 文案与剧本实际内容一致，禁止货不对板（平台红线）
- [ ] 投流脚本 0-3 秒画面在成片中真实存在
- [ ] 措辞过审安全（无极限词、无低俗擦边）
